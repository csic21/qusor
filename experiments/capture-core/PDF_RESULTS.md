# PDF 原件、混合知识与恢复本机资格记录

日期：2026-11-08。状态：独立 Core schema2 的本机子项通过，生产集成与完整阅读 UI 未通过。关联 C-08/C-09、F-LIB-01、F-READ-02/03、F-NOTE-01、F-SRC-01、F-DATA-01、F-EXT-01/02/03/05/06。规格见 [PDF 捕获资格](../../docs/product/pdf-capture-qualification.md)，决定见 [ADR 0015](../../docs/architecture/adr/0015-pdf-core-snapshot-archive.md)。

## 环境与固定输入

Linux/WSL、固定 Rust 1.97.1、debug、锁定离线依赖。仍使用原生 PDFium 8125 的 [已验证运行库和夹具](../pdf-provider/RESULTS.md)，没有 WebView/PDF.js、账号、云服务或用户文档输入。真实 PDF 是自建 MIT 两页英文文本，原件 SHA-256 为 `7fd4515748d1b14265ab2af851fe02fc231493e9bf443feb978f1dcff605fd9c`。

[JSON 证据](evidence/linux-pdf-core.json) 记录宿主/原生 worker/运行库 hash、公开 SDK 源码、仓库外作者依赖图、当前源码指纹、全部 CLI 与原生渲染结果。独立作者构建前后宿主和原生 worker 二进制保持相同。作者 SDK 中没有 Core、SQLite、Host、PDFium 或 Wasm 运行器；构建作者所需签名库不等于向 guest 开放宿主服务。

| 原件与文档 | 二进制 CAS 可靠发布，文档及提取引用、提交日志、凭据、操作事实、outbox 和索引任务共同提交；相同导入操作幂等、改标题冲突 |
| 普通插件通路 | 仓库外 SDK 作者真实构建签名 relay；guest 经 SelectionRead 获取本次 PDF 选段，再自行构造 CapturePropose；宿主复核原件/提取/页版本、范围和授权 |
| 预览与批准 | 来源标题、展示页码、原文和用户备注可检查；预览无摘录凭据，错误批准摘要拒绝；备注与原文分开保存，旧批准/跨库/改草稿/跳过读取拒绝 |
| 混合顺序 | 实际 PDF 导入→PDF 摘录→文本摘录全局 revision 为 1/2/3，文本局部 ID 仍为 1；局部实体 ID 不冒充提交序号。V1 导出在混合库明确拒绝 |
| 完整恢复 | 统一 archive 同时含文本、PDF 原件、提取映射、摘录、历史来源和操作关系；空库恢复后 archive 完全相等，PDF 原件逐字节相同，新的原生 worker 得到相同映射和页图 hash，原摘录可精确解析 |

本轮验证器执行 224 条命令、198 项 CLI 场景，另有 2 次真实 PDF 原生 worker 运行。198 项包含原 C0 的 104 项文本回归；共 24 次 CLI exit(86)，其中旧 C0 为 10 次、新 PDF 为 14 次。当前实验 46 项 Rust 测试全部通过：原有 22、PDF 契约 10、PDF Core 7、PDF Host 7。PDF Core 测试另外运行 17 个提交/恢复/迁移子进程退出点，不与 CLI 计数混淆。

## 重要边界

PDF 导入与摘录保存是两个事务：已导入原件可以没有摘录，取消选段不会删除资料。本轮导入是可信原生实验服务供给，不代表正式 library 插件或用户文件选择 UI 完成。快照 JSON 只能由该可信供给链产生；Core 校验内部关系和原件 hash，不自行解析 PDF，也不接受 guest 自报提取结果。

保存的文字明确是版本化 engine stream。旋转页的阅读行序仍未解决，不声称可靠 canonical reading text。此次实际 PDF 为英文；契约中的组合字符、emoji、未知映射单元测试不能外推为中文/复杂字体 PDF 已通过。

语义提取 revision 不含渲染报告摘要，缩放不应改变锚点来源版本。导入幂等校验仍包含完整快照的审计证据；同操作换渲染证据会冲突，不能悄悄替换旧证据。原件版本、提取版本和提交 revision 各自独立。

统一导出上限 64MiB、4096 次提交；原件 16MiB、16 页、100000 字符。查询仍做全库一致性验证，不承诺生产规模性能。崩溃可留下无引用文件，尚无产品级 GC；进程退出不证明断电或系统重启。包管理锁及当前 Host 门不等于跨数据库分布式事务或 OS 沙箱。

尚未验证 NSH 窗口、像素传输、原生拖动选区、高亮交互、缩放/进度/重开、IME、可访问性、EPUB、中文 PDF 或多平台。完整导入→阅读→笔记→回源旅程与生产 Core/SDK/安装器仍按门槛推进。
