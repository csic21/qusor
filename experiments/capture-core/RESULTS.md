# C0 本机捕获资格记录

后续 schema2 增量见 [PDF 与混合知识本机记录](PDF_RESULTS.md)。本文件及其原始 JSON 是 C0 文本资格的历史基线，不把当时的源码指纹当作后续实现的当前指纹；新的混合回归和兼容证据另行留存。

日期：2026-11-08。状态：Linux/WSL 独立 CLI 切片通过；生产集成与阅读 UI 未通过。关联 F-EXT-01/02/03/05/06、F-SRC-01、F-DATA-01、C-08，见 [规格](../../docs/product/capture-qualification.md) 与 [ADR 0013](../../docs/architecture/adr/0013-capture-core-qualification.md)。

## 环境与输入

本机 Rust 1.97.1、锁定依赖、debug 构建，全部 Cargo 操作离线。SQLite 使用 rusqlite 0.32.1 bundled，Unicode grapheme 规则固定 unicode-segmentation 1.13.3。具体内核、命令输出、宿主及源码 SHA-256、仓库外 SDK 源码和全部生成夹具 hash 留在 [JSON 证据](evidence/linux-capture-core.json)。

两个普通身份来源包分别提供本地合成归档文本及带公共来源入口的合成文本；同一公开契约，无来源服务分支。文本含中文、emoji、组合字符及重复引文，第一份请求超过既有 4KiB 通用能力预算，实际走独立 64KiB 捕获通路。输入及资产使用项目 MIT 许可；签名种子为公开测试夹具，不访问账号、网络、用户资料。

## 实际结果

| 验证 | 实际结果 |
|---|---|
| 仓库外作者 | 从权威源码导出契约及签名 SDK，实际构建、签名并安装；图中无 Host、Core、SQLite、Wasmi 或内部路径依赖；宿主二进制在作者验证前后 hash 相同 |
| 提案与确认 | 实际 Wasm 调父 broker；预览无知识凭据，错误草稿 hash 不保存，用户备注与原文独立；签名也不能绕过恶意字段和非法定位拒绝 |
| 持久化 | CAS 原始文本可靠发布，七类正式表在单事务中保存；重启查询与精确定位成功；相同操作幂等、同键改备注冲突、独立意图共用 blob 但保留不同记录 |
| 撤权竞争 | 真实线程屏障验证 commit-first 阻塞撤权并保留唯一凭据，revoke-first 不保存；旧 epoch、另一个 Host/库/安装的批准被拒绝，包管理锁覆盖原生动作 |
| 故障恢复 | CLI 7 个捕获进程 exit(86) 与 3 个恢复 exit(86)；提交前无凭据，提交后可查原凭据，重试只留一条；恢复可见数据始终为空或完整 |
| 插件生命周期 | CLI 实际卸载两个来源，知识及导出不变；Rust 测试在同一安装上实际初始化私有状态、Wasm 升级迁移和成对回退，知识、凭据、导出与定位不变 |
| 定位失败 | 重复引文歧义、找不到原文、grapheme 中间边界、错误单位、版本/hash/归一化均拒绝；合同测试另含 ZWJ、旗帜、CRLF 与重叠匹配 |
| 导出恢复 | 三次保存保留两份唯一 blob；空库恢复后完整导出相等；缺 blob、坏 blob、错误 schema、注入授权字段、重复 JSON 键及非空目标拒绝 |
| 损坏检查 | 真实磁盘 blob 缺失/损坏、SQLite 关系或主键与记录不符、未知 schema、符号链接均拒绝，不以相似文本修复 |

验证入口执行 128 条命令、104 项 CLI 场景（包括上述 10 次真实进程退出）。新实验 22 项 Rust 测试通过：契约 8、Core 9、Host 5；受影响 Wasm 32 项及包管理 59 项回归通过。新实验和仓库外作者 Clippy 零警告、格式检查通过；受影响旧实验的格式与 Clippy 另行通过。架构守卫及 42 项 Python 反例测试通过。

Core 测试还独立运行 7 个提交和 3 个恢复的子进程退出点；这些是测试中另外执行的故障检查，不与 CLI 的 10 次混为一次计数。

## 限制与后续

当前上限为 4096 条记录和 64MiB 导出；查询进行全库一致性验证，未做生产规模性能承诺。无引用 blob 和 staging 残留可在崩溃后存在，本轮没有产品级垃圾回收。恢复只支持空库，不支持合并迁移或任意 schema 升级。

批准仅为原生内存对象；CLI 每次显式授予当前捕获动作，不构成长驻产品授权 UI。包管理库与 Core 没有跨数据库事务，实际共享的是当前宿主提交/撤权门和动作期间的包管理锁。

本轮原始文本 profile 不等于完整提取/QLA 协议，外部来源入口不等于外部精确跳转。进程退出不证明断电、内核重启或 OS 沙箱；无 NSH 窗口、PDF/EPUB 阅读、微信读书账号接入、云服务、原生多平台或移动渠道成绩。生产 learning-domain 继续无业务实现，正式 SDK、安装器和阅读闭环仍待集成与验收。
