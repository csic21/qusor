# 应用入口与装配

当前只有目录约定，尚无产品应用。完整边界见 [目录架构](../docs/architecture/workspace-layout.md)。

这里只放平台入口、composition root、依赖注入、打包和预装插件清单。候选 desktop/mobile 入口须在对应 NSH 验证通过后创建，不表示首发平台已决定。

通过公开贡献目录展示功能插件；阅读/笔记/AI 流程不写在入口内，不按官方包 ID 提供权限或隐藏实现。预装清单只决定附带什么，不改变安装/授权/执行链。

Host 保留插件管理、故障恢复、通用内容查看和完整导出恢复的最小入口，不依赖可卸载工作流插件，也不复制完整阅读器或笔记编辑器。
