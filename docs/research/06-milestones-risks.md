# QUSOR M-1 M0 M1 任务清单 风险与验收

日期：2026-11-07。当前状态：技术规划完成，以下实现与实验全部待执行。本文的时长为工作量估计，性能为验收目标，没有已通过的五端运行成绩。

## 1 开工顺序与投入假设

M-1是可行性门，不是产品开发的第一轮。先跑最难的移动输入、离线阅读Surface、PDF链接/选择、精确锚点，再扩展业务。没有M-1通过记录，不启动大规模M0。

建议职责：TL技术负责人（架构/协议/风险）、UI工程师（NSH/平台/阅读交互）、Core工程师（Rust/存储/定位/Agent）、QA（语料/设备/回归）。这是工作职责，不要求四个全职人员；同一人可以承担多个角色，但不能把并行估算当单人工期。

| 阶段 | 预计投入与前提 | 时间判断 |
|---|---|---|
| M-1 | 约18–25工程人日；至少两名具Rust/平台能力工程师并行；设备和SDK提前就绪 | 1–2周可完成首轮筛查；遇移动补丁、PDFium构建或资源handler缺口另估，不承诺两周全部修复 |
| M0 | 约40–60工程人日，另有测试和发行成本；复用M-1已通过路线 | 2工程师+兼职QA时4–6周目标；单人通常8–12周以上 |
| M1 | 约50–70工程人日，含画布/知识/同步基础与回归 | 2工程师+兼职QA时5–7周目标；同步复杂度可要求独立延长 |

上述估计不是逐项精确求和，实际spike结束后重估。M0允许先完成本地闭环；M1把云同步作为有独立验收门的工作流，不能以同步未完成掩盖本地能力，也不能提前宣称五端已同步。

## 2 证据登记与验收环境

每项记录：任务ID、状态、负责人、日期、NSH/依赖SHA、Rust工具链、构建模式、OS/设备/CPU/RAM/DPI/GPU、语料hash、步骤、预期、实际结果、日志/截图/录屏、缺陷编号、决定。记录结构是M-1计划模板，本轮未生成假结果。

状态仅可为：未开始、进行中、源码已确认、构建通过、模拟器通过、真机通过、失败、阻塞。源码已确认不能填为真机通过。

五端基础矩阵：

| 平台 | NSH声明下限 | 最少运行环境 | 关键操作 |

### M-1 Go 条件

必须同时满足：

- 五端最低产品路径可安装启动，Rust↔TSX、SQLite、文件权限可用。
- 中文输入和选区无阻断错误；文字fallback、DPI、触控可验证。
- PDF和EPUB至少各一条真实离线路线通过，能选择→持久锚点→重开回原文。
- 精确来源协议和Core独立边界成立；无静默错源。
- 编辑基线可保存、恢复和导出；高级RichEditor失败允许明确延后。
- 画布规模边界和性能路径已测；无障碍基础有可行实现。
- 资源/桥接无已知越权，依赖许可和分发路径可接受。
- 所有未过项有明确影响范围；影响核心阅读/数据完整性时No-Go。

Go-with-limit只能用于已明确延期的非核心高级特性，例如复杂表格或大规模图动画；不能用于“移动尚未启动”“EPUB其实只能纯文本”等基础缺口。

## 6 统一验收预算

先用release构建固定设备和语料，取至少30次操作记录p50/p95。涉及模型时本地处理、网络、模型耗时分别计时，不让云模型延迟掩盖UI阻塞。

| 项目 | 初始门槛 | 失败处理 |
|---|---|---|
| 持久化 | 已确认写入重启不丢；事务全有或全无 | 阻断 |
| 锚点 | 300同字节版本样本无错误来源；新版本歧义明确 | 错跳阻断，未找到可见可修 |
| IME | 组合态/撤销/emoji场景不丢字不重复 | 阻断核心编辑 |
| 阅读首屏 | 普通PDF/EPUB本地p95<=2s | 分解I/O/解析/渲染，扫描大书另报 |
| UI反馈 | p95<=100ms | 不接受同步长任务堵主线程 |
| Canvas | 1000节点/2000边，桌面约200可见p95<=33ms；移动约100可见同门槛 | 裁剪/LOD/后台布局，扩大规模另测 |
| 图大规模 | 10000节点可搜索、局部打开、保存 | 不要求全量文字同时绘制 |
| 搜索 | 1万chunk桌面p95<=300ms、移动<=700ms；Recall@10目标>=85% | 分词/过滤/索引策略回归 |
| 引用回答 | 人工支持度目标>=95%，无证据题至少95%明确资料不足 | 限定使用范围并修检索，不能伪造来源 |
| 内存 | 连续50次开关/翻页有界稳定，记录RSS及各cache | 无界增长阻断 |
| 同步 | 同op100次重试只应用一次；丢所有Realtime仍收敛 | 正确性阻断 |
| 导出迁移 | 空库导入ID/hash/引用/附件/历史符合manifest | 阻断 |
| 隐私 | 未授权原文/文件/凭据零出站 | 阻断 |
