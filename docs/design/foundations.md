同时完成 [NSH官方设计文档及更新核对](nsh-check.md)。其原生行为层与应用样式层的分工用于本项目设计，当前实验固定版本保持不变。

| 参考思想 | QUSOR 的具体规则 | 检查方式 |
|---|---|---|
| Linear：减少边框噪声、校准导航与对齐 | 工作区、文档身份、正文、辅助工具各有层级；列表按共同基线对齐；只在需要区分职责时加分隔 | 隐去配色后仍能判断当前区域和主动作 |
| Reader：高亮与批注围绕正文 | 默认不显示完整保存表单；选区先提供轻量动作，主动写想法后再开编辑区 | 连续阅读无需绕过表单；关闭编辑区回到原选段 |
| Heptabase：内容身份连续、辅助工具随对象变化 | 同一引用在笔记和阅读中保留来源；辅助区服务当前任务，不按插件不断增加常驻侧栏 | 切换对象/组件后仍能核对原文和位置 |
| Raycast：动作可见，快捷键帮助熟练使用 | 高频动作有文字入口；更多操作按任务分组；命令面板与快捷键是补充入口 | 不知道快捷键也能完成关键流程 |
| Apple/Fluent：清晰、可恢复、语义排版与可见焦点 | 原生控件优先；明确焦点归还；状态靠近对象；文字角色和交互状态跨插件一致 | 键盘、系统字号、深浅主题和错误恢复逐项验收 |

## 当前界面的具体问题

依据 [C8 实际保存截图](../../experiments/nsh-reader/evidence/dynamic-pdf/final-vault-bound/fourth-saved.png) 与当前 TSX：

- 文件入口、文件名、翻页与缩放平铺，缺少“从哪里来、当前在哪里”的导航层级。
- 右侧表单默认常驻，阅读和编辑没有清楚的工作状态转换。
- 来源、全局提示、引文、想法和完成状态集中在一张卡里，主次不稳定。
- 保存成功后重复显示成功文字和禁用按钮，缺少自然的继续阅读路径。
- 样式直接散布在临时代码里，尚无可复用的组件角色、尺寸和状态约束。

截图中大块留白主要来自合成 PDF 本身，不能据此认定 PDF 排版失败。固定版式原件必须保真；EPUB/笔记的可重排正文另按行宽和字号设计。

## 视觉语言

采用暖白阅读表面与中性外壳；强调色只用于当前操作、焦点与少量状态。减少厚边框、大阴影和处处圆角卡片。正文、导航和编辑器通过空间与层级区分。

| 语义 token | 浅色初值 | 使用位置 |
|---|---|---|
| `surface.app` | `#F4F3EF` | 工作区底层 |
| `surface.navigation` | `#ECEDE8` | 稳定导航 |
| `surface.content` | `#FFFFFF` | 原件页面、编辑表面 |
| `surface.reading` | `#FAF9F5` | 可重排阅读主题；不改写 PDF 页图 |
| `text.primary` | `#242824` | 正文、标题、主操作 |
| `text.secondary` | `#596159` | 来源、说明、次级信息 |
| `border.subtle` | `#D9DDD5` | 必要的区域分隔 |
| `action.background` | `#315B46` | 默认提交动作背景；前景为配对的action.foreground |
| `selection.background` | `#E7EDE5` | 行选中；同时提供文字/图标变化 |
| `annotation.highlight` | `#F5DF8B` | 标注底色；不用于表达 AI 结论 |
| `status.danger` | `#A23732` | 阻止当前操作的错误 |

token 表示语义，不允许插件把品牌色硬编码到基础文字与控件。深色/纸张主题通过同一角色映射，不采用整体反色；PDF 原页主题变换须另验，不能修改引用或原件。正式实现需测量实际控件各状态的对比度；不得从本表宣称无障碍已通过。

完整浅/深色初值、前景/背景配对及hover/pressed/disabled/focus角色保存在 [tokens.json](tokens.json)。该文件是设计数据，不是已接通的NSH配置；实现时统一映射到NSH主题与宿主样式层，页面只引用角色。PNG/SVG是静态评审工件，其颜色不应直接复制进各功能代码。

## 排版与空间

| 角色 | 初值（逻辑点/pt） | 规则 |
|---|---|---|
| 窗口/工具区标题 | 15–16 / 行高 22–24，medium | 当前文档身份清楚，长标题省略并能查看全名 |
| 页面标题 | 24 / 34，semibold | 用于资料库等内容标题，不用于每个工具栏 |
| UI正文/列表主信息 | 14–15 / 22 | 中文和混排使用平台字体回退 |
| 说明/来源 | 12–13 / 18–20 | 降低权重同时保持可读，不用极浅灰隐藏信息 |
| 可重排正文 | 18 / 30 起，可调 | 中文约30–40字/行起测；宽度、行距随阅读设置验证 |
| 引文 | 15–16 / 25 | 与想法编辑器分开，保留来源入口 |

固定 PDF 文字大小来自原页与缩放，不以 UI 正文字号强行重排。代码、公式、英文和中文分别用实际样本检查。

间距以4为基础：4、8、12、16、24、32。工具内部通常8，字段组12–16，区块24，页面边距24–32。普通按钮高度32–36，输入框至少36；触控交互目标至少44，紧凑桌面图标可用更大的透明命中区。圆角以6/10为主，浮层使用轻阴影，不给每段内容套卡片。

这些是初值，不允许为了凑栅格裁切内容。系统字号放大时优先折叠辅助区和调整布局，不压缩文字或点击区域。

## 公共组件与状态

实现先建立语义组件：`ActionButton`、`IconButton`、`NavigationItem`、`DocumentRow`、`SourceReference`、`QuoteBlock`、`NoteEditor`、`InlineStatus`、`EmptyState`、`RecoveryPanel`。这是设计角色，不是已发布 SDK 名称。

- 每个可操作组件提供普通、hover、pressed、focus、disabled、loading 状态；键盘焦点可见，不仅改变文字颜色。
- 同一区域通常只有一个默认提交动作使用primary样式，例如编辑区的保存。导入、打开工具等普通命令使用default/outline/ghost，不因位于右上角就使用primary。破坏性动作有明确含义和位置。
- 来源作为可操作对象：标题、页码/章节、回到原文；只读引用与用户输入有不同容器和标签。
- 本地回源、切换面板和打开编辑器采用按钮/导航语义，安静动作可用ghost样式；外部网址才使用链接语义。需要继续选择的命令使用省略号，如“导入资料…”；立即提交的“保存想法”不加省略号。
- loading 不清空输入、不抢焦点；异步返回只更新仍对应当前对象的区域。
- 成功状态靠近刚保存的内容，仅保留一处。短提示不替代持久记录，普通完成反馈不阻断下一步。
- 错误说明发生了什么、哪些内容保留、可执行什么操作。例如“这份 PDF 暂不支持打开。原资料与想法已保留。”并按真实原因提供重试/选择其他文件，避免展示协议或实验预算术语。

## 焦点、键盘与动效

优先级：当前输入或选区 → 用户显式打开的工具 → 阅读正文。打开想法编辑器才移入输入焦点；保存成功不自动抢走光标。关闭工具回到触发入口或原选段；异步加载和状态提示不得改变焦点。

使用平台标准编辑快捷键；菜单展示实际可用的快捷键。`Esc` 逐层关闭最上层临时工具，不能静默丢草稿。标签、可访问名称、选中/禁用/展开状态由原生语义提供；不能只依赖 Canvas 像素。

过渡仅服务展开、切换和定位，初值120–180ms；跟随减少动效设置。原文定位时可短暂强调目标，不持续闪烁。所有尺寸、对比度、屏幕阅读器与输入法仍须实际平台验收。
