# 背单词工作区设计（v1 样例）

更新：2026-11-11。状态：v1 样例已按本规格实现于原生工作台（headless 10 项 + macOS 实窗五张 + 同一 Core 重开恢复，见[实窗记录](../../experiments/nsh-reader/evidence/vocab-workspace-live/README.md)）；窗口内 fixture 与真实 Core（0.5 能力）两种数据来源分别标注，不把样例或 wire 通过当成正式产品界面。关联 F-LEARN-01、F-UX-01/02、C-11/C-12/C-16；功能范围见[词汇插件规格](../product/vocab-plugin.md)，公开能力见 [ADR 0036](../architecture/adr/0036-vocabulary-study-capability.md)，分区见[组合规格](composition.md)，导航规则见[导航层级](navigation-hierarchy.md)。

## 目标与原则

- 背单词是**一屏一件事**的工作区：当前只有一张卡、四个评分动作和剩余数量。不是词库管理，也不是统计仪表盘。
- 学习状态由 Core 决定：界面只提交评分，不自行推算间隔或改写到期时间。
- 未评分前不泄露答案；释义与例句在“显示答案”之后出现，避免把浏览当成记忆。
- 数据来源始终可见：“本机 Core”与“样例数据”不能混用；读取失败保留当前卡与已显示内容，给出可重试状态。
- 安静：没有连续动画、没有庆祝弹层、没有自动播报；评分后只在原位更新下一次到期。

## 布局

宽窗（≥1000pt）：宿主顶栏（工作区身份、可信返回、外观菜单）下方两列：

```text
┌──────────────────────────────────────────────────────────────┐
│ 宿主：QUSOR · 返回产品设计 · 背单词〔插件〕 · 外观           │
├───────────────┬──────────────────────────────────────────────┤
│ 词书导航 240  │ 学习区 自适应（max 640）                     │
│ 词书 + 计数   │ 进度/剩余 · 卡片 · 显示答案 · 四档评分        │
│ 数据来源说明  │ 空态 / 错误 / 下一次到期                     │
└───────────────┴──────────────────────────────────────────────┘
```

窄窗（<900pt）：单列。词书导航折叠为顶部一行“词书”选择；学习卡占满宽度，四档评分保持一行四等分。宿主外层返回始终回到进入前工作区，与插件内部选择区分。

尺寸与节奏：词书行高 52–64；卡片内边距 28–36；词条字号 34–40、行高 1.15；释义 16/26；例句 13/21 muted；评分按钮高度 44、间距 8；内容最大宽度 640；圆角 10；焦点环 2pt。

## 视觉

- 语义 token（`theme.json`）：`surface-content` 学习区底、`surface-sidebar` 词书导航底、`surface-selected` 当前词书、`border-subtle` 分隔、`text-primary/secondary/muted`、`accent` 选中与焦点、`surface-raised` 卡片容器。
- 字阶：词条 34–40 semibold；词性/音标 13 muted；释义 16 regular；例句 13 muted；计数 12 secondary；空态标题 15 semibold。
- 答案展开用 120ms 淡入与高度变化；遵循 reduce-motion，不做翻卡 3D 或粒子效果。
- 四档评分只用文字与语义色，不用图标假装不同含义：不认识（again）、模糊（hard）、认识（good）、很熟（easy）。文字按钮同一尺寸刻度，不换行。

## 数据来源状态

- 词书导航底部固定一行来源说明：“本机 Core · 由 vocab 插件读取”或“样例数据 · 窗口内样例”。
- 真实模式失败（包缺失、权限撤销、Core 读取失败）时保留 fixture 并标注“样例数据”，不把失败显示成空词库。
- 评分的 `request_id` 是 Core 幂等键；同一次点击重试复用同一 id，不能因为重试多排一次复习。
- 未实现的入口（词书导入、提醒、统计、AI 释义）不出现可用按钮；需要说明时以禁用项或状态行表示。

## 组件

### 词书导航

- 每本书一行：标题、`到期 N · 新词 M`；当前书有选中态与左侧 2pt 指示。
- 只显示有权限读取的词书；空库显示“还没有词书”与“导入词书（下一增量）”禁用说明。
- 键盘可达：上下移动选择，Enter 进入学习。

### 学习卡

- 顶部：当前书标题、`待复习 N · 今日新词 M`、数据来源。
- 卡片：词条（term）；未显示答案时只有“显示答案”主操作；显示后出现释义、例句与四档评分。
- 评分后：卡片原位显示“下一次复习：X 分钟后 / X 天后”，短暂停留后自动进入下一张；也可立即点击“下一张”。
- 队列为空：“今天完成”，显示今日已学数量与下一次到期；不自动扩大每日新词预算。

### 状态

| 状态 | 呈现 |
|---|---|
| 加载 | 卡片骨架/“正在读取词书”，保留上次内容直到新数据到达 |
| 空队列 | “今天完成”，说明今日新词预算与下次复习时间 |
| 读取失败 | 保留当前卡，显示“暂时读取不到，已保存进度没有丢失”与“重试” |
| 评分失败 | 保留卡片与四档选择，显示可重试；不假装已安排 |
| 窄窗 | 顶部词书选择 + 单卡；返回词书列表保留选中书 |

## 键盘与可访问性

- 空格/Enter：显示答案；数字 1–4 对应四档评分；`Esc` 清除当前展开或回到词书选择。
- 评分按钮是真实按钮，读屏标签为“评分：认识，下一次约 3 天”一类可理解文本；不用只有颜色的指示。
- 焦点在评分后回到“下一张”或下一卡；“今天完成”可被读屏读到。

## 验收

- Given 真实 Core 有两本词书，When 进入工作区，Then 导航显示两本书与到期/新词计数，来源为“本机 Core”。
- Given 第一本书有 3 张新卡，When 选择并开始，Then 每次显示一张，显示答案后出现四档评分；评分后下一次到期与剩余数量来自 Core。
- Given 同一评分重复提交或重试，Then 不重复安排；换评分复用同一 operation id 时报冲突并保留原安排。
- Given 走完队列，Then 显示“今天完成”，不自动引入超过每日新词预算的卡片。
- Given 宿主未提供真实数据或读取失败，Then 窗口显示样例并明确标注“样例数据”，不伪装成本机 Core。
- Given 900×680，When 选择词书、显示答案、评分与返回，Then 单列仍可完成同一闭环，焦点不丢失。
- Given 同一 Core 重开，Then 到期时间、剩余数量与复习历史一致（由 storage-sqlite 与宿主模块测试覆盖）。

## 实现与证据

- 原生样例：`experiments/nsh-reader/native-workbench` 的 `fixture.vocab` 工作区；真实模式经 `VocabHost`（普通签名包 + 0.5 wire + 真实 SQLite Core）。
- 证据：headless 交互测试 + macOS 实窗渲染；记录见[词汇工作区实窗记录](../../experiments/nsh-reader/evidence/vocab-workspace-live/README.md)。
- 本设计不替代正式产品安装界面、词书导入、提醒或其他平台验收。
