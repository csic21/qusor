## 文字与空间

| 语义角色 | 桌面起测值 | 用法 |
|---|---|---|
| 内容标题 | 24 / 34，600 | 当前文档/页面标题，避免每个面板都用大标题 |
| 面板标题 | 15 / 22，500–600 | 当前工具、任务或局部区域 |
| 界面与标签 | 14 / 22，400–500 | 导航、按钮、对象标题与常规操作 |
| 列表主信息/会话正文 | 14–15 / 22–24 | 不用说明字号表达主要内容 |
| 来源与元信息 | 12–13 / 18–20 | 保持对比度；路径、状态和出处不能因颜色过浅消失 |
| 代码 | 14 / 24，400 | 独立等宽字体、等宽数字；系统放大时可调 |
| 可重排阅读正文 | 18 / 32，400 | 起测 30–40 个汉字/行；窄窗按可用空间调整 |

表中数值是相对逻辑单位，浏览器样稿以 CSS px 表达；原生 pt/dp 与平台缩放需要重新映射和实测。手机 UI 以 16、正文以 18 起测，编辑字段至少 16；不把桌面 14 直接缩放到手机。

原生 UI 优先平台字体，中文按平台使用苹方/系统黑体/Noto 等适当回退；拉丁 UI 可评估 Inter。代码可评估 JetBrains Mono/SF Mono/Consolas；中文注释单独回退。最终字体的离线交付、授权、回退和平台渲染另验，产品不以远程字体服务为运行前置。字重只在实际支持时使用，不伪造极细字；中文不使用负字距。

间距采用 4/8/12/16/24/32。默认导航行 36–40、对象标签行 40、桌面按钮 32–36、输入框至少 36；触控命中区至少 44 起测。内容区边距 24–32；需要对照时先折叠工具或导航，保持文字大小。

## 候选主题

清透中性外壳、清晰内容表面、克制紫灰强调。基础色和完整配对见 [visual-tokens-v2.json](visual-tokens-v2.json)，这是候选设计数据，未连接运行配置，也不覆盖 [v0.1 tokens](tokens.json)。

只在窗口、区域职责或浮层需要时使用边界；不为每行内容加圆角卡。普通行通过间距和轻量 hover 表达；当前对象通过底色、文字与可访问状态共同表达。主动作每组通常一个。阅读纸色与代码语法色有独立语义；固定 PDF 原页保持原貌。

## 标签的统一行为

- 身份：标签引用对象和视图状态；文档带版本、笔记带实体修订、文件带项目/工作树/路径及缓冲版本、任务带任务 ID。当前提供者不构成对象身份。
- 方向：开发默认横向；研究可选择纵向，按工作区保存偏好。使用共同对象模型，避免同时显示重复的完整打开列表。
- 宽度：横向标题约 112–200 起测，40 高；数量超出空间进入可搜索列表，不缩小字体或自动关闭脏标签。同名文件显示必要的父路径，完整路径可访问。
- 固定：保持可见顺序，使用图标与文字语义；取消固定是独立动作。非固定对象关闭按钮始终可发现，不仅 hover 可用。
- 未保存：圆点和可访问名称共同标记。关闭需要“保留草稿并关闭”“取消”或明确的放弃动作。只有真实写盘回执才使用“已保存”。
- 切换：保留光标、滚动、选段、未提交输入与当前对象上下文；异步消息不能切换当前标签。原生键盘遵循平台习惯，中文组合输入不被快捷键截断。
- 关闭：焦点回到相邻对象或明确空态；重开可恢复草稿。关闭任务/终端视图不停止其执行对象，停止另有宿主动作。
- 恢复：提供者不可用时显示对象身份和替换/导出/恢复入口；不能用空白页面掩盖草稿或内容。

样稿实现其中的对象切换、固定、关闭、重开、草稿提示与溢出入口；原生拖放排序、跨窗口、重启持久恢复和真实文件写盘另验。

## 区域与窄窗

主内容可用性决定能否展开三栏：阅读正文建议至少 540–600，代码主区至少 480 起测；这些是设计假设，实际由字体/材料/平台验证。需要同时看参考或 Agent 时，先收起局部导航；仍不足则辅助区进入覆盖工具或独立详情页。不得为了保留三栏把主文字降到 11–12。

手机只有一个主内容对象，打开标签从对象切换器管理；目录、引文、Agent 和终端进入工具或详情页。返回保留位置与输入。底部主目的地和内容对象标签承担不同职责。
