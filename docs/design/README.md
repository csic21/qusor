## 当前采用的方向

采用“安静的阅读工作台”：暖白阅读表面、中性导航与工具、清晰对齐和少量强调色。资料整理保持可扫描，阅读保持连续，写想法时才进入编辑状态。画布等未来工作区沿用同一外壳、组件和来源规则，其排期不因此提前。

后续交付采用可运行的纵向流程：先画清主流程和状态，再把原生界面与真实数据一起接通；审查同一批中文材料、窄窗、错误恢复和键盘路径。功能验收必须同时给出界面证据与业务证据。
