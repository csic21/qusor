# 想法工作区设计（v1 候选）

更新：2026-11-10。状态：首个正式切片的交互规格；原生样例已按本规格实现 v1（窗口内 fixture，6 项 headless 交互测试通过，见[UI v1 记录](../../experiments/nsh-reader/evidence/notes-workspace-ui/README.md)）；正式包、公开能力与真实 Core 装配另按门槛验收。关联 F-NOTE-01、F-SRC-01、F-UX-01/02、C-11/C-12/C-16；功能范围见[想法插件规格](../product/notes-plugin.md)，导航规则见[导航层级](navigation-hierarchy.md)，分区见[组合规格](composition.md)，验收见[设计验收](review.md)。

## 目标与原则

- 想法工作区用于**回看、整理和引用**，不是第二个编辑器。默认安静：列表承担浏览，详情承担阅读与复制。
- 原文（引文）与个人想法在视觉、复制和操作上始终分开；界面不把两者混成一段“内容”。
- 来源可信：页码与资料标题来自 Core；其他资料不假装能定位；原件缺失明确说明。
- 只读操作即时反馈；任何读取失败保留已有内容，不清空列表或选中项。
- 键盘、选取与右键是一等交互，不是鼠标的补充。

## 布局

宽窗（≥1000pt）：宿主顶栏（工作区身份、可信返回、外观菜单）下方三列：

```text
┌──────────────────────────────────────────────────────────────┐
│ 宿主：QUSOR · 返回产品设计 · 想法〔插件〕 · 外观             │
├───────────────┬──────────────────────┬───────────────────────┤
│ 插件导航 208  │ 列表 320–380         │ 详情 自适应（max 720）│
│ 范围/计数     │ 搜索 + 行            │ 引文/想法/来源/动作   │
│ 状态说明      │ 加载更多             │ 选取工具条 + 状态行   │
└───────────────┴──────────────────────┴───────────────────────┘
```

窄窗（<900pt）：单列。列表与详情二选一；详情顶部有“返回想法列表”，返回后保留筛选、搜索、选中项与滚动位置。宿主外层返回始终回到进入前工作区，与插件内部返回区分（见导航层级）。

尺寸与节奏：行高 76–92；行内边距 14；详情内容最大宽度 720；引文块与想法块间距 16；详情动作行与正文间距 20；圆角 8；焦点环 2pt。

## 视觉

- 语义 token（`theme.json`）：`surface-toolbar` 导航与列表底、`surface-content` 详情底、`surface-selected` 选中行、`border-subtle` 分隔、`text-primary/secondary/muted`、`accent` 焦点与选中指示。
- 字阶：资料标题 13 semibold；行内引文 13 regular、最多两行；想法预览 12 secondary、最多两行；元信息 11 muted；详情正文 14/22；引文块 14/23 并加左侧 2pt 强调线。
- 选中行：`surface-selected` 底 + 左侧 2pt accent 指示；悬停：`surface-hover`；焦点：2pt accent 外环，不改变布局。
- 预览截断用省略号与“完整内容”入口，不用渐隐遮罩伪造完整。
- 动画只用于选择/详情切换的 120ms 淡入与滚动定位；遵循 reduce-motion。

## 控件尺寸

所有按钮与文本动作共用一个尺寸刻度（`ui.tsx` 的 `control()`、`Tool`、`TextButton`）：

| 尺寸 | 高度 | 水平内边距 | 圆角 | 图标 | 文本 | 用途 |
|---|---|---|---|---|---|---|
| compact | 28 | 9 | 6 | 15 | 12 | 选取工具条、横幅动作、内联次要动作 |
| regular | 30 | 10 | 7 | 16 | 13 | 顶栏工具、菜单触发器、返回 |
| large | 34 | 14 | 8 | 17 | 13 | 主操作、侧栏行 |

- 同一行按钮使用同一尺寸；图标按钮最小 28×28，带文字按钮高度不低于 28；主操作不与页脚重复出现。
- 搜索/输入高度 32；菜单项高度 30、水平内边距 10、圆角 6；菜单弹层内边距 5、最小宽 200、圆角 10。
- 焦点环 2pt、偏移 2pt；悬停/按下分别用 `surface-hover`/`surface-pressed`；禁用统一 0.4 透明度。
- 图标不单独缩放；文本按钮不换行；强调只用 raised/filled 一种，避免同一动作出现两个入口。
- 引文强调线用独立 3pt `View` 而不是 `borderLeftWidth`：固定 NSH 的 macOS 开发宿主会把单侧边框画成横线，独立竖条在两个渲染路径一致。

## 组件

### 插件导航

范围：`全部想法`、`当前资料`；每项右侧计数；下方一行说明“想法保存在本机；原文与个人观点分开”。当前范围有明确选中态；切换范围不丢失搜索词。

### 搜索

占位“搜索想法、引文或资料”；输入即过滤当前已加载页；右侧显示结果计数与清除按钮；`mod+f` 聚焦。搜索为空显示“没有匹配的想法”与“清除搜索”，不清空 Core 或已保存内容。

### 列表行

- 首行：资料标题（省略）+ 页码徽标（`第 3 页`）；复合选区显示“跨段”徽标。
- 第二行：引文预览（引号样式，最多两行）。
- 第三行：想法预览（最多两行）与保存时间；预览截断时行尾显示“完整内容”提示点。
- 行作为单一可访问元素：`accessibilityLabel` 为“《标题》第 N 页：引文开头… 想法开头…”。
- 选中、悬停、焦点三态可同时辨认；双击/Enter 打开来源。

### 详情

- 头部：资料标题、页码、保存时间、复合标记；窄窗有“返回想法列表”。
- 引文块：只读、可选取；左侧强调线；下方“复制引文”。
- 想法块：Markdown 只读渲染，可选取；空想法显示“这条记录没有个人想法”，不伪造占位内容。
- 截断提示：列表预览有界时显示“列表只显示开头”与“读取完整内容”；加载中显示进度，失败保留预览并给“重试”。
- 来源行：`打开所在页`（当前资料）、`先打开《…》后可定位`（其他资料）、`原件缺失，无法定位`（缺原件/版本不符）。
- 动作行：打开所在页、复制引用、更多（菜单）。只读状态明确，不显示编辑/删除等未实现按钮。

### 右键菜单（行）

`打开所在页` · `复制引文` · `复制想法` · `复制引用` · `读取完整内容`（仅截断时） · 分隔 · `编辑想法`（禁用，附“编辑能力在下一增量”） · `删除想法`（禁用，附“需要历史与撤销”）。

右键先选中该行再弹出菜单；菜单在指针处打开；Shift+F10 在聚焦行上打开同一菜单；Escape 关闭并把焦点还给行。

### 选取工具条

在引文或想法中拖选/长按选中文本后，详情顶部出现紧凑工具条：`复制选中`、`复制为引用`、`取消选择`。选取为空时工具条消失。工具条不遮挡正文，不改变滚动位置。

### 复制格式

- 引文：仅引文原文。
- 想法：仅个人想法。
- 引用（Markdown）：`> {引文}\n\n— 《{资料标题}》第 {N} 页`。
- 引文与想法：`《{标题}》第 {N} 页\n\n{引文}\n\n我的想法\n{想法}`。
- 复制成功在详情状态行显示“已复制引文/想法/引用”，3 秒后淡出；失败显示“复制未完成，可选中文本手动复制”。

## 交互

### 指针

| 操作 | 结果 |
|---|---|
| 单击行 | 选中并显示详情；列表滚动不改变选中 |
| 双击行 | 打开所在页（当前资料）或提示需先打开（其他资料） |
| 右键行 | 选中该行并在指针处打开菜单 |
| 右键选中文本 | 平台文本菜单（复制）；应用工具条提供引用格式 |
| 拖选文本 | 显示选取工具条；不自动滚动详情 |
| 点击空白 | 保持选中；Escape 清除选中（宽窗） |
| 滚动到底 | 有下一页时显示“加载更多”；加载中禁用重复点击 |

### 键盘

| 键 | 结果 |
|---|---|
| ↑ / ↓ | 在列表中移动选中并更新详情 |
| Home / End | 首/末条 |
| PageUp / PageDown | 翻页移动选中 |
| Enter | 打开所在页或提示 |
| mod+C | 有文本选取复制选取；否则复制当前想法的想法正文 |
| mod+shift+C | 复制引用 |
| mod+F | 聚焦搜索 |
| Shift+F10 / Menu 键 | 在聚焦行打开右键菜单 |
| Escape | 关闭菜单/清除选取/窄窗返回列表 |

焦点顺序：插件导航 → 搜索 → 列表 → 详情动作 → 正文选取区。焦点环不因详情切换丢失；列表虚拟化时选中项滚入可见区。

### 状态矩阵

| 状态 | 列表 | 详情 | 可执行动作 |
|---|---|---|---|
| 加载中 | 骨架行（不伪造内容） | 空 | 无 |
| 空库 | “还没有保存的想法”+ 阅读提示 | 空 | 去阅读 |
| 筛选空 | “当前资料没有想法”+ 清除筛选 | 空 | 清除筛选 |
| 搜索空 | “没有匹配的想法”+ 清除搜索 | 保留上次选中或空 | 清除搜索 |
| 读取失败 | 保留上次列表 + 错误行 | 保留上次详情 | 重试 |
| 预览截断 | 行尾提示点 | 截断提示 + 读取完整内容 | 分块读取 |
| 其他资料 | 行可选中 | “先打开《…》后可定位” | 仅复制 |
| 原件缺失 | 行可选中 | “原件缺失，无法定位” | 仅复制 |
| 只读 | 正常 | 无编辑/删除 | 复制/回源 |

## 可访问性与平台

- 行、菜单项、工具条按钮都有可读标签与状态；计数与复制结果通过状态行播报。
- 全键盘可完成选择、打开、复制与返回；不依赖悬停。
- 高对比/深色主题使用同一语义 token；字体放大不裁切页码与时间。
- 触屏：长按行等同右键；长按文本使用系统选取；工具条在窄窗位于详情头部下方。
- 移动/其他平台在各自资格中验证，不因桌面样例宣称通过。

## 实现映射

- 原生样例（`experiments/nsh-reader/native-workbench`）按本规格实现交互与视觉，使用窗口内 fixture 验证布局、选取、右键、键盘与窄窗；fixture 不代表正式数据。
- 生产：`plugins/notes` 通过公开 `notes.read` 能力读取 Core；Host 提供原生控件、菜单、剪贴板与焦点；列表分页与正文分块见 ADR 0034。
- NSH 能力：`ContextMenu`/`Menu`/`MenuItem`、`View` 的 `focusable`/`onPress(e.clickCount)`/`onContextMenu`、`Menu.popup`、`keymap.bind`、`Clipboard.writeText`、`TextView` 的 `selectable`/`onSelectionChange`。
- 编辑/删除/标签/收藏不在本版：需要 Core 写入用例、历史/撤销、公开写能力与冲突规则后再设计，不以禁用按钮以外的假入口出现。

## 验收清单

- 宽窗三列与窄窗单列均无双重侧栏；插件身份与两层返回清楚。
- 列表分页、范围筛选、搜索、空态与错误态可观察。
- 行右键菜单、Shift+F10、文本选取工具条与复制格式符合上表。
- 完整正文分块读取成功与失败都有明确状态，失败保留预览。
- 当前资料回源成功；其他资料与缺原件不假装定位。
- 仅键盘可完成核心任务；焦点不丢失。
- 900×680 下返回列表保留筛选、搜索、选中与滚动。
