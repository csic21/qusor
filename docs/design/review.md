最新基座结构按 [v0.3的SL-01–12](shell-layout.md) 验收：去掉阅读插件后外壳成立，手动工作无需 Agent，导航/对象/活动区分，工具输入不串目标，布局收敛保留返回。下文阅读路径是业务验收，不再承担全产品信息架构的默认定义；静态研究图不能勾选任何原生通过项。

适用于新功能与组件替换。技术实验另保留自身成绩；当前原生技术探针不能替代本表。设计稿、可运行原型和正式实现分别标记。

## 每次动手前

变更说明应关联Feature ID，写清用户任务、分区、组件角色、公开能力及状态；检查是否复用已有组件、是否保持主内容和来源上下文。新增区域或组件角色先更新组合规格，再实现，避免每个插件各造一套布局。

## 同一条流程同时检查

| 检查 | 必须拿到的证据 |
|---|---|
| 信息层级 | 正常视图可判断当前位置、当前对象、主操作；无永久无关表单或重复成功提示 |
| 阅读与编辑 | 真实中文/混排材料；未选段、选段、写想法、保存和继续阅读都可见 |
| 完整状态 | 空库、导入中、坏文件、页面失败、未保存、保存失败/未知、缺原件与插件不可用有真实结果 |
| 键盘与输入 | 可见焦点、Tab顺序、Esc与关闭归还；中文IME组合态、emoji与光标单独实测 |
| 窄窗/字号/主题 | 1440、1100、800、390等代表尺寸与系统字号放大；实际对比度与触控目标；无法运行的平台标未验 |
| 数据真实性 | “已保存”对应持久回执；重开、引用回源、导出恢复确实成功 |
| 插件替换 | 同角色普通提供者可切换；格式/版本不符拒绝；停用后内容保留；新权限不自动继承 |
| 资源生命周期 | 换组件/换文档旧回调拒绝、输入停止、任务取消与真实释放分别确认；旧实例关闭未确认/额度不足时保留资料与草稿并如实反馈 |

关键任务：导入→找到资料→阅读→选段→想法→保存→继续阅读→稍后从笔记回原文→完整导出恢复。至少覆盖一条错误恢复路径和一条无鼠标路径。记录用户停顿、误触、内容丢失、定位漂移和恢复能力，不只提供成功截图。

## 合入/阶段交付规则

功能实现与对应UI一起交付。内部协议或平台前置实验可独立进行，但其临时界面必须标为探针，不能直接成为正式工作区。真实业务功能没有可运行入口、明确状态和对应界面证据时，保持未完成。

实现后对照设计稿与状态表逐项记录偏差及原因；NSH能力缺口先验证原生替代，不默默增加WebView或降低功能要求。数值与视觉目标以实际测试修订，未测项目保留。后端绿灯、一次截图和设计文档都不等于完整UX验收。


## 已观察到的阅读交互问题

最新[默认原生GUI记录](../../experiments/nsh-reader/evidence/native-editor-shutdown-gui-default/record.json)保留了多次拖选端点未命中：端点落在字形间隙或可见文字外，必须缩短拖动后才取得选段。成功选中并保存证明当前精确链路可用，不证明自然拖选已经顺畅。该项继续关联 F-READ-02/03、F-UX-01/02，不因保存／恢复通过而移除。

后续须用真实字间／词后间隙、行末、跨行及旋转页验证选择边界与反馈。若按几何行带解析最近插入边界，应先明确确定性规则、有效行范围和歧义拒绝条件，再修改行为及旧用例；不能借相似文本搜索或跨行猜测制造精确定位。空白／出界取消、旧帧拒绝与已写草稿保留仍需同时通过。

F-AGENT-01–05 使用 [工作台交互与体验门槛](agent-workbench.md) 和 [AW-01–10](../product/agent-workbench.md)。必须同时核对真实会话/模型、跨后端委派、唯一输入所有权、文件实际状态、取消/恢复以及界面可理解性。屏幕状态识别不能作为后端完成证据；设计图不能替代真实接入，鼠标接管/中文组合态/窄窗/读屏须独立记录。知识保存与项目代码整合分别验收。

## v0.2 视觉与标签追加验收

后续整体定位修正：通用基座首先按 [AF-01–07](agent-foundation.md) 验证Agent、能力与交互组合。以下v0.2标签规则只在适用场景生效，不要求所有任务具有文件标签、代码或侧栏。

关联 F-UX-01/02、F-EXT-04/06、F-AGENT-04/05，对照 [任务研究](../research/10-product-design-synthesis.md) 和 [候选规范](visual-refinement.md)：

- 阅读、整理和开发都检查主信息字号、中文/拉丁/代码混排、实际行高与清晰层级；元信息不能挤占主信息的可读性。
- 横向/纵向标签切换、固定/取消固定、同名路径、溢出、脏缓冲关闭与重开各有明确结果；关闭任务视图不隐式停止执行。
- 字号放大或窄窗时折叠区域并保留上下文；不缩小字体维持三栏；手机标签切换与底部目的地分开。
- 候选文字/背景配对先计算对比度，实际控件各状态、键盘焦点和可访问语义仍需原生验证；样稿通过不替代生产资格。

## 六端基座与阅读入口增量

C-12/C-15/C-16、F-LIB-01、F-READ-01/02/03、F-UX-01/02、F-EXT-04/06/07 按[六端规则](cross-platform-shell.md)与[文字阅读记录](../../experiments/nsh-reader/evidence/native-reading-entry/README.md)逐项验收：

- 书架可选书籍、打开本机文本或输入文本；取消/空文本失败后原资料和章节保持。正式入库和窗口内暂存明确区分。
- 原生选文、复制、翻章、返回再读彼此连贯；换章节后旧选区与迟到事件不能作用于新正文。
- 宽屏工具区、窄屏单页目录/检查器和导航抽屉分别观察；抽屉打开后背景操作及可访问树隔离。
- 插件增长由宿主安排入口、标签和工具，安装不自动铺满一级导航；提供者给出角色、适用上下文、紧凑呈现和退出/恢复资料。
- macOS、Windows、Linux、iOS、Android、Web 独立记录构建、实际运行、输入和恢复。macOS 窄窗不替代移动真机，单次 AX 检查不替代完整读屏/键盘资格。
