功能归属沿 [通用基座](agent-foundation.md)，区域与组件沿 [组合规格](composition.md)，视觉沿 [原生方向](native-art-direction.md)。下列规则是设计与接入验收要求，不是新增已发布的 manifest 字段或 SDK 类型。

## 宿主保持统一秩序

宿主拥有全局导航、任务/资料身份、标签组、返回栈、面板开合、溢出菜单、焦点和受信界面。插件注册入口、内容角色和适用动作；宿主按当前平台、可用宽度和用户选择安排位置。安装插件不自动固定一个一级目的地，也不自动展开多个面板。

固定入口采用稳定分组和用户排序。未固定功能从能力列表与搜索进入，增长到几十个插件时仍不生成几十个一级图标。插件提供的标题、图标、状态与动作使用宿主公共组件，不能另画一套应用导航或复制一条全局状态栏。

标签表示打开的对象或任务视图，目的地表示进入哪类工作，两者分开。桌面可展示对象标签和可选分组；手机通过在读/打开对象列表切换。关闭视图、返回上层和停止 Agent 执行是不同动作，不能互相替代。

## 相同语义，不同操作密度

| 对象 | 桌面 / 宽屏 | 手机 / 窄屏 | 稳定规则 |
|---|---|---|---|
| 全局导航 | 可收起侧栏，键盘与指针可达 | 按需的导航抽屉 / 切换器 | 宿主管理顺序与当前目的地；背景操作隔离 |
| 常用操作 | 紧凑工具栏，显示适用快捷键 | 少量主要操作，其他进入工具菜单 | 相同命令、可用条件与结果，不靠 hover 才能发现 |
| 对象标签 | 水平标签或用户选择的分组 | 对象切换列表，当前内容占主位 | 身份、未保存状态和关闭规则保持一致 |
| 目录 / 检查器 | 按需并排，可调整宽度 | 单页或受控面板，有明确返回 | 不把正文和工具同时挤成窄条 |
| 阅读 | 舒适版心、目录和字号工具 | 正文全宽，目录切换为单页 | 来源、章节、选文和返回书架保持清楚 |
| 文字输入 | 键鼠编辑、可见焦点与惯用快捷键 | 触控目标至少 44pt，键盘避让与组合态 | 输入不因换视图丢失；未保存状态如实显示 |
| 窗口与边缘 | 平台真实窗口控件，保留 caption 区 | 状态栏、安全区、底部手势区与系统返回 | 插件不能覆盖平台控件或宿主受信层 |

断点跟随可用空间；交互密度也考虑设备类型。窄桌面窗口需要单页布局，宽平板仍需要触控尺寸。禁止单纯缩小字体以容纳桌面三栏。布局与输入设备组合需分别验证，不能从一个尺寸推断平台合格。

## 平台适配边界

| 目标 | 需独立核对的部分 |
|---|---|
| macOS | 系统窗口控件、菜单、系统字体、键盘焦点、文件选择与输入 |
| Windows | caption 预留、系统字体与缩放、快捷键、文件选择、触控/指针混用 |
| Linux | 原生窗口/控件、字体回退、桌面文件对话框、输入法和窗口管理器差异 |
| iOS | 安全区、动态字号、触控、系统返回/呈现、软键盘与文件访问 |
| Android | 系统返回、Insets、触控、软键盘、文件权限与生命周期 |
| Web | 浏览器历史、键盘与指针、文件入口和受限能力；独立适配，不规定原生外观 |

采用平台系统字体与可缩放字阶，颜色使用语义 token；浅深主题、选中、按下、禁用、焦点、加载与错误由公共组件一致呈现。视觉变化仍须在实际文字、原生控件和输入中观察，不能从 token 数值宣布现代化已经完成。

## 插件接入的必要资料

每个内容/工具提供者至少说明：角色与兼容格式、当前对象上下文、最小可用空间、宽屏和紧凑呈现、主要动作与溢出动作、焦点入口/出口、输入/取消、加载/空/错误/缺能力状态，以及停用/替换后的恢复路径。

宿主据这些信息选择呈现方式。提供者可实现单平台能力或多平台实现；不适用的平台由宿主清楚显示缺少的能力或提供替代。插件不能自行突破分区、夺取焦点、覆盖权限提示，或把另一提供者的授权带入自身实例。

多个提供者的状态按视图实例隔离。切换书籍、章节或提供者时，旧选区与迟到事件不能作用于新内容。正式引用仍保留来源版本和定位契约，窗口内的显示片段和 UTF-16 选择偏移不自动变成永久锚点。

## 用真实流程验收基座

先用阅读和非阅读任务共同检查：选择资料 → 阅读/选文 → 返回 → 切换任务；同一动作在宽屏、窄屏、键盘和触控路径中均能理解。另检查插件增加、缺失、停用、替换、未保存输入、后台任务以及错误恢复。

当前 [原生样例](../../experiments/nsh-reader/native-design/README.md) 已加入独立的阅读贡献 fixture。它证明候选界面的局部显示与操作，不证明公开 SDK 已支持通用装配。390pt 窄窗在 macOS 上运行只构成布局证据，不能写成 iOS / Android 真机通过。真实插件包、各平台运行和正式保存仍按原门槛交付。
