## 视觉重点

用浅灰外框组织白色功能面板；深色外观使用有层次的中性色。窗口级面板以细边界、8px 间隔与 12px 连续圆角区分；行项使用紧凑排版、分组条和柔和选中态。预览缩略图表达内容，普通列表行不再各包一层卡片。

默认进入工作区集合。打开对象后，宽窗显示“全局导航—当前工作区内容—当前视图”；内容列表可以收起。文稿、画布、会话、阅读以同一贡献目录进入，外壳没有按具体功能 ID 分支。实际包隔离与 SDK 装配另行完成。

用户随后明确：所附书库图只作为阅读插件参考，基座要能适配这种形态。阅读插件工作区应拥有书库导航、格式分类、检索、筛选、封面网格/列表及阅读工具；宿主按空间与用户选择收起通用导航和对象列表，保留可信返回与受信界面。这个完整工作区模式属于下一组合验证切片，本轮对象样例的文本阅读视图不算书库模式已交付。详见 [阅读规格](reading-workspace.md)。

| 区域/角色 | 样例尺寸与行为 | 提供者 |
|---|---|---|
| 全局导航 | 200px，保持稳定；不重复罗列当前对象 | Host |
| 当前工作区列表 / leading | 288px；按固定/其他内容分组，可收起；剩余区域满足约 900px 时才自动呈现 | Host 的贡献目录样例 |
| 当前工作面 / content | 占剩余空间，8px 外间距；主区工具与对象标签保持独立 | 一个当前视图提供者 |
| 对象信息 / auxiliary | 256px，默认关闭；打开时收起内容列表；不足 1120px 时临时收起全局导航 | Host 组合信息样例 |
| 搜索 | 520px，整窗居中、距顶 96px；模态时背景从无障碍树隐藏 | Host + NSH Command |

宽度数字是实验参数，不能替代其他尺寸、字体放大、超长标题与大量标签的验收。900px 研究窗口也不代表移动界面。

## 字体、状态与材质

使用平台字体。UI 主字号 13px，辅助 11/12px，常用标题 16/17px；文稿正文 16px、29px 行高、400 字重，文稿标题 29px。字号与行高、字重共同表达层次；标题、摘要与类型在列表中各有位置。用户文字可选择，输入使用原生 Input。

语义色集中在实验的 `theme.json`；面板、画布、普通/选中/按下状态、边界、正文、辅助文字、焦点分别命名。主题切换时也更新浮层。图标沿用同一套自绘细线词汇，工具图标有可访问名称。画布提供文字语义摘要；完整读屏与键盘路径仍须单独验收。

高频切换直接响应，不加整窗入场或装饰动画。按钮有按下与键盘焦点样式；菜单与搜索复用 NSH 基础行为。窗口保留系统控制和真实拖动区。

## 本轮操作闭环

- 集合打开对象，列表选择与对象标签保持一致；不同视图各用自己的内部结构。
- 文稿输入在切换、关闭标签并重新打开后保留于窗口；没有持久保存回执，不显示“已保存”。
- 信息面板跟随当前对象；与局部列表互斥，关闭后可恢复原布局。
- 搜索打开即获得输入焦点，类型/标题/摘要参与过滤，回车打开；Esc 先清空查询，再返回原视图。
- 会话样例显示尚未连接，发送不可用；阅读只是功能目录的一个平级样例。
