# 基座与插件的导航层级

2026-11-09。细化 C-07/C-11/C-12/C-16、F-UX-01/02、F-EXT-01/04/06；承接[外壳布局](shell-layout.md)、[区域与提供者](composition.md)和[跨端规则](cross-platform-shell.md)。用户指出两个侧栏开关与返回过于相似，收起后难以辨认已进入插件，要求按顶层设计修正。本页记录候选规则；macOS 窗口内样例的实际范围见[验证记录](../../experiments/nsh-reader/evidence/native-navigation-hierarchy/README.md)，不代表正式插件或六端交付。

## 目标与设计判断

用户在内容中工作时，始终能回答：所属工作区是什么、当前使用哪个插件、眼前是什么对象、一个返回会去哪里。导航收起、进入插件和专注阅读各有明确含义。

截图暴露三个问题：全局导航与内容列表各有收起开关，主工具栏又有同形开关；无目的地文字的左箭头混入其中；两栏收起后，只留下对象标题和标签，插件提供者与所属工作区退出视野。图形微调不足以补齐这些信息，需要统一区域与导航语义。

## 稳定的层级与身份

| 信息 | 表达 | 所有者与行为 |
| --- | --- | --- |
| 基座 | 窗口顶部持续显示 QUSOR | 宿主；插件进入后仍保留 |
| 所属工作区 | `产品设计`，可回到该工作区概览 | 宿主解析对象位置；与侧栏显隐无关 |
| 当前界面提供者 | 图标、`文稿`、低强调的`插件`标识 | 宿主按贡献目录呈现；信息面板可核对提供者 |
| 当前对象 | 对象标签与内容标题 | 对象身份独立于提供者，切换提供者不改变归属 |
| 完整插件工作区的来源 | `返回产品设计`或`返回功能` | 表示此次进入的真实来源；不固定回首页 |

普通对象的顶部路径为 `QUSOR · 导航 · 产品设计 › 文稿〔插件〕`，对象标题放在标签与正文。导航收起时路径保持原位。插件名称说明谁提供当前界面，不把知识数据变成插件私有财产；正式数据和卸载后访问继续沿用 Core 不变量。

完整插件工作区可以拥有自己的导航、工具和主内容。此时宿主顶部保留 `QUSOR · 返回产品设计 › 阅读〔插件〕`；插件正文内部显示当前资料以及`书架`返回。外层返回说明去哪里，局部返回说明回到什么集合，两者不共用一个无文字箭头。

## 一个导航区与一种开合动作

- 默认只有一个宿主导航区，使用`空间 / 产品设计`范围切换承载全局入口和当前工作区内容。范围切换只替换导航内容，当前对象和输入继续保留。
- 导航区开合只从窗口顶部的`导航`按钮操作，位置保持稳定，选中态表示已展开。可访问名称为`隐藏导航 / 显示导航`。导航内容内部不再复制收起按钮。
- 点击对象进入对应提供者；切换对象标签属于同级切换，顶部提供者身份跟随当前对象。只收起导航不会改变提供者、对象、标签或返回来源。
- 进入完整插件工作区时，退出宿主导航与对象标签，插件按自身角色组织内容。宿主保留提供者身份与外层返回；插件不能把宿主返回藏进自身菜单。
- 信息面板是支持工具，关闭使用自己的`关闭信息`，不冒充导航动作。窗口不足时按既有预算收敛；不得重新生出第二个宿主导航区。

窗口内样例使用 248pt 的一个导航区；这是当前桌面参数。范围标题、分组、普通列表行、插件身份复用公共组件与语义 token，不能因为插件数量增加而增加常驻层级或图标列。

## 返回与恢复

| 操作 | 可观察结果 | 不应附带的变化 |
| --- | --- | --- |
| 隐藏 / 显示导航 | 当前内容宽度改变，顶部路径保留 | 不切换对象、不新增历史、不退出插件 |
| 选择工作区路径 | 到当前工作区概览，原对象仍在打开列表 | 不关闭对象或清除草稿 |
| 插件内`书架` | 回到当前插件的资料集合 | 不退出插件、不改变外层来源 |
| 外层`返回产品设计` | 回到进入前的对象，并恢复导航范围、开合与信息面板 | 不强制展开侧栏、不返回固定首页 |
| 外层`返回功能` | 回到进入前的功能目录及原导航开合 | 不跳转到上一次对象来代替真实来源 |
| 插件内选择宿主`功能样例` | 明确离开插件并打开宿主功能目录 | 不在仍激活的插件后面偷偷切换目录 |

正式旅程还须保存可恢复的位置与焦点，并解决未提交输入和真实资源退役。当前样例的来源快照只覆盖对象、目录、导航范围、侧栏偏好和信息面板；输入由贡献自身的窗口内状态保留。不得据此承诺滚动位置、退出应用后的草稿或真实插件实例恢复。

## 紧凑呈现与失败状态

窄桌面窗口保留相同的宿主层级；插件书库导航用带文字的`书库导航`入口进入单页，返回当前资料集合。主操作先保证文字可读，次级动作进入更多菜单，提供者身份不因导航收起消失。

iOS / Android 的一级返回由系统导航栈承接：先返回插件内上一页，到插件入口后再回来源工作区；显式离开插件可放在具名命令中。手机不照搬桌面两排工具栏；对象标题、提供者和宿主归属仍需可辨。Web 分别处理浏览器历史与对象标签。这些规则仍待各端运行验证。

提供者停用、缺失或加载失败时，宿主保留对象、所属工作区、提供者状态和返回入口；仅依据已验证的格式能力提供替代查看或导出。不得把空白页、导航收起或回到首页当成失败处理。此状态仍需真实插件链验收。
