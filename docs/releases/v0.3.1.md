# QUSOR 0.3.1

本版完善想法与阅读之间的回源体验。

## 本次更新

- 想法详情新增“打开原文”，把来源格式、文档与节次、摘录编号传给 Reader。
- Reader 校验回源目标属于当前文档、节次，并确认摘录同时存在于该节已保存选区与笔记；无效目标明确报错，相同启动令牌去重。非空 quote 找不到时的精确失败路径、失败回滚和所有关闭路径仍未验证，不宣称已做到绝不回退页首。
- Reader 接受回源后生成带摘录编号的焦点 Surface，并在界面标注 PDF 几何定位提示或 EPUB 字符区间。当前宿主受控阅读面仍按 Surface ID 末尾三段加载，未解析焦点编号、未绘制可见几何高亮，也未验证页面宽高比；因此 PDF 可见几何高亮尚未完成与验收。EPUB 暂不提供原生几何高亮。

以上改动源码已落位；本版构建待本轮回填。`source_capture` 用例源码虽已存在，但本轮尚未执行、无结果；自动化验证与实窗/模拟器/真机验证分栏记录，未验证项不因本说明视为通过。

## 验证范围

- 自动化：既有的 Reader 书架、打开文档、受控 Surface、节次导航，以及 Notes 列表/筛选/搜索/编辑/删除测试不覆盖本次“打开原文”链。Reader 的 `source_capture` Wasm→SQLite Core 回源用例源码已落位，但本轮未执行、无结果；Notes E2E 只校验“打开原文”动作 ID，未真正点击，故点击→宿主解析→Reader 完整链、跨格式筛选回源、去重、失败回滚及所有关闭/返回路径均未证明。
- macOS：v0.3.1 未在真实窗口验收；PDF 可见几何高亮、从 Reader 返回 Notes 的状态恢复与安装体验均未验证。
- Android 模拟器：v0.3.1 未在模拟器验收，手机布局、返回键与回源路径均未验证。
- Android 真机：v0.3.1 未在真机验收，手机布局、返回键与回源路径均未验证。

## 安装与签名

- macOS 产物为 **ad hoc 签名**，**未使用 Developer ID 签名，也未公证**；其他 Mac 可能被 Gatekeeper 拦截，需要手动放行。
- Android 产物使用 **debug keystore 签名**，不适合商店或正式渠道分发。
- 本版**仅支持侧载**；macOS 与 Android 均不提供商店更新语义。安装前请核对 `latest.json`、`latest.json.sig` 与对应平台归档；签名清单的校验不等于应用功能或实窗验收。
