# ADR 0013 独立捕获与 Core 持久化资格切片

日期：2026-11-08。状态：[独立实验本机通过](../../../experiments/capture-core/RESULTS.md)，生产集成未通过。关联 F-EXT-02、F-SRC-01、F-DATA-01，验收见 [C0 规格](../../product/capture-qualification.md)。

## 决定

新增独立 Workspace `experiments/capture-core`，不向生产根 Workspace 增加业务成员。以普通签名插件、宿主确认门、Core 快照事务和导出恢复构成有界纵向验证，不以安装元数据或合成写入计数替代知识保存。

公开契约只描述来源、原始文本及选段。实验作者拿到裁剪后的契约和签名 SDK，不获得 Host、SQLite、运行器或 Core 实现。公开请求上限 64 KiB；既有通用能力请求仍保持 4 KiB。较大的捕获请求使用单独的有界原始 broker 入口，不放宽旧协议预算。

宿主冻结已验证安装包，在当前会话中接收提案。确认对象只存在于原生宿主，绑定启动、库、安装、包摘要、会话、授权世代、草稿摘要和用户操作；不能从插件 JSON 反序列化为批准。授权变更与复核后提交共享宿主串行门。该门不是两个独立数据库之间的分布式事务，也不构成 OS 安全沙箱。

Core 不依赖 UI 类型或来源服务。原始 UTF-8 blob 以内容哈希命名，先可靠发布并同步目录，再在 SQLite 的一次事务中建立全部正式引用、凭据及派生索引。崩溃可留下无引用 blob，但不得留下缺失 blob 的成功凭据。插件生命周期不得删除这些 Core 数据。

导出携带规范知识、blob 和审计事实；恢复只接受空库并严格校验哈希、引用及边界。恢复的来源审计不构成活动插件授权。当前文本 profile 不替代未来完整提取和阅读定位协议。

## 依赖与限制

SQLite（rusqlite bundled）验证真实事务，fs2 验证单写者，SHA-256 固定 blob 和草稿身份，unicode-segmentation 固定 grapheme 边界；依赖与独立作者图登记在 `config/architecture.toml`。生产 learning-domain 继续保持无业务实现和零外部依赖。

该实验只证明实际执行过的本机边界。进程退出不证明断电安全，CLI 不证明 NSH 交互，有限 UTF-8 profile 不证明全部文档格式。结果与源码指纹在实验目录留存后，才能据此推进生产决策。
