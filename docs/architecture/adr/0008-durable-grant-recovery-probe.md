# ADR 0008 持续授权与新策略会话恢复实验

日期：2026-11-07。状态：实验增量，生产集成未通过。关联 C-08、F-EXT-01/03/05/06、EXT-B03/B04、EXT-P04/P08/P13 的本机子项。

## 问题

[签名包实验](../../../experiments/extension-package/README.md) 已有禁用安装事务，但重启后如何恢复明确授权、拒绝旧会话仍无执行证据。NSH 原生依赖阻断不影响 B2 此项工作；不因此提前实施业务 UI 或绕过阅读 Surface 门槛。

## 决定

在既有独立实验中增加有界持续授权记录，唯一可持续能力为公开协议已有的 `document.metadata.read`。授权绑定安装 ID、完整包摘要、库、文档、文档版本、授权世代、到期时间和策略版本；不持久化选区、运行许可、文件句柄或正式知识写入批准。CLI 的授权命令代表可信宿主管理调用，不代表已经完成用户授权界面。

安装实例首次授权时绑定一个库，该绑定独立保存，禁用/撤权/更新不解除它；重装创建新实例，才可重新选择库。记录与启用意图、安装修订、世代、幂等回执在同一 SQLite 管理事务中更新。禁用、撤权、更新和卸载使旧授权失效；成功更新继续保持禁用并要求重新授权。安装状态与实际运行观测分开：此实验恢复的只是策略会话，不把启用意图显示为插件已运行。

恢复通过现有 `extension-host` 的注册、授权、启用与会话策略，不另实现一套能力判定。实验存储适配器先验证持久绑定与有效期，再向策略宿主提供明确的授权。活跃会话仅存在于当前 Store 内存；跨进程重放不能取得当前会话。恢复再次检查资源和有效期，不能因为曾经创建会话便永久沿用过期授权。

独立作者仍只消费导出的公开 API/包格式。新增普通身份的元数据权限测试包，使恢复场景不依赖无法持续恢复的选区权限。没有给官方包增加任何分支或特权。

## 验证与边界

[验证脚本](../../../experiments/extension-package/validate.py) 在不同进程执行授权提交边界中止、重新打开、幂等重试、新会话、旧会话重放、范围/版本不匹配、更新清授权及禁用/撤权恢复。Rust 回归补充同进程的授权与会话判定；实际结果以 [实验结果](../../../experiments/extension-package/RESULTS.md) 及机器证据为准。

这不证明恢复后实际 Wasm 调度、真实 Core 提交与撤权交错、私有状态迁移/回滚、长驻双插件监督、生产授权 UI、平台安全沙箱或移动渠道通过。完整生命周期仍按 [规格](../../product/plugin-lifecycle.md) 分项验收。

## 依赖与代价

仅实验宿主新增直接依赖权威 `extension-host`，[依赖策略](../../../config/architecture.toml) 同步登记；其原已在实验运行器的传递依赖中。生产 Workspace 与公开 SDK 依赖不变。

实验管理 schema 的扩展不构成生产迁移方案。损坏或未知记录必须拒绝恢复，不能猜测授权；CLI 也不访问用户真实文档或外部服务。过期时间使用宿主本地时钟，不证明恶意回拨时钟防护。
