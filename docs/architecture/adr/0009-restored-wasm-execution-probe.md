# ADR 0009 从持久授权恢复受限 Wasm 调用

日期：2026-11-07。状态：独立实验增量，生产集成未通过。关联 C-08、F-EXT-01/03/05/06、EXT-B03/B04、EXT-P04/P06/P08/P11 的本机子项。

## 问题

[ADR 0008](0008-durable-grant-recovery-probe.md) 只恢复策略会话；旧合成 Probe 每次自行授予选区读取权限，不能证明实际安装包仅凭仍有效的持久授权恢复执行。接下来必须连通“已验证存储包 → 新会话 → 受限运行 → 宿主能力 → 结果接受”，同时保留已有运行预算与独立作者边界。

## 决定与边界

复用独立 Wasm 实验运行器，新增可信宿主构造 `Probe::from_authority`，消费已经注册和授权的 Host、安装、会话、精确能力资源、受控服务响应及授权期限。构造不新增权限，必须经权威 Host 验证安装/manifest/包摘要与实际冻结模块绑定。该入口不向 guest 暴露，不是插件提供凭据的 wire API。

包 Store 的 execute 先复核持久授权和资源版本，再消费一次恢复会话，读取管理库内冻结包，交给上述入口；不重开下载路径、不调用会自行授权的 Probe::new。执行失败也不复活已消费 token，重新尝试须新会话并重新检查当前授权。

每个执行片段、宿主调用及结果接受点重验授权期限和 Host 生命周期。guest 的 JSON 请求仍走公开 0.1 capability request。先用 Host 判权，再要求 capability/resource 与本次服务响应精确匹配；即使 Host 另授权其他文档，也不能把当前响应错当作那个文档的数据返回。

服务响应仅为显式 synthetic 元数据，包含库、文档、版本和测试标题；不访问 Core、不证明真实文档存在或定位正确。持续授权仍仅允许精确范围 document.metadata.read，选区/写入批准不恢复。普通作者模块实际读取这些宿主返回字节；新版本调用次数不同，验证没有沿用旧模块。

## 预算、错误与恢复

沿用已固定的 Wasmi 模块/导入检查、无 start 函数、内存/表/栈上限、指令片段、总 fuel、host call 次数、响应大小和运行 deadline。未知 imports、错误范围、权限升级、trap、超量内存及死循环有界拒绝。deadline 不抢占原生编译或阻塞宿主代码；完整 worker 监督和 OS 隔离仍有独立门槛。

此增量为持单写者锁的同步一次性调用，管理命令与执行串行；不证明长驻多插件、并行持久撤权、worker 回收失败、真实 Core 提交与撤权交错或知识写入幂等。失败可再次显式调用，但不自动重放具有副作用的请求；本实验没有外部副作用。

## 证据与下一步

[包实验](../../../experiments/extension-package/README.md) 的仓库外 SDK 作者构建元数据两版本和故障包，保持宿主字节不变，跨进程运行安装/授权/重启/撤权/更新/卸载路径。原 Wasm 实验的回归必须继续通过，不能只跑新增 metadata happy path。具体成绩及限制见 [结果](../../../experiments/extension-package/RESULTS.md)。

未新增生产依赖或 Workspace，运行器原有依赖不变。随后按 [迁移实验设计](../../../experiments/extension-package/MIGRATION.md) 验证私有状态与包成对恢复，防止普通 install 绕过迁移，再验证长驻双插件监督。此决定不改变 UI 技术路线、首发平台、AI 或云范围。
