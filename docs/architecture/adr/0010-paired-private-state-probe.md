# ADR 0010 私有状态与包的成对迁移和回滚实验

日期：2026-11-07。状态：独立实验增量，生产集成未通过。关联 C-08、F-EXT-03/05/06、EXT-B04、EXT-P08/P13 的本机子项。依据 [生命周期规格](../../product/plugin-lifecycle.md) 和 [实验设计](../../../experiments/extension-package/MIGRATION.md)。

## 问题

既有禁用安装和授权/执行恢复只切换包摘要，尚不能证明插件私有状态升级后可回退。若先升级包、再单独保存迁移结果，进程中断可能使旧代码读到新版状态；如果只新增迁移命令而保留普通 install 更新路径，也会绕过配对约束。

## 决定

继续在独立包实验中验证，不新增生产 Core/SDK 能力。签名包固定资产 assets/lifecycle.json 声明协议 1、私有 Schema、迁移模块和可接收的来源 Schema；Schema 不从包版本推断。描述和迁移模块都在完整包签名中，作者从导出的公开格式/API 和工具在仓库外构建。

私有迁移模块不允许任何 imports，使用 alloc/migrate ABI，复制旧状态到新的受限 Wasm 内存，返回新字节。宿主不硬编码偏好字段转换。迁移和运行预检复用已有 Wasmi 安全配置，限制模块、内存、栈、表、输入输出、总指令和执行时间。预检检查真实 run/memory/ABI/alloc/state_check，broker 始终拒绝业务能力，不为预检创建授权。

管理库升级至 schema 3，增加不可变快照、当前 head、保留历史配对、至多一个每安装 pending 和私有操作终态回执。快照绑定安装 ID、包摘要、Schema、字节摘要。全部状态是 Host 管理的插件私有数据，不含 Core 知识或凭据。

准备事务保存新内容和 pending，撤销持续授权并递增修订/世代；提交后旧会话失效。真实迁移和新运行入口预检在事务外执行。最后管理事务同时切换新包和新 head、保留旧配对、写回执并清 pending，保持禁用。只有最终事务提交后才报告升级成功。

准备前验证失败保留旧授权；准备后迁移/预检失败保留旧包和旧状态，保持禁用且世代不回退，返回明确失败终态。重开遇到完整 pending 先检查绑定，再将其终结为 interrupted，不自动重跑迁移；同操作 ID 只返回已保存终态。普通命令和私有命令共享操作 ID 冲突规则。

有当前私有 head 的安装禁止普通 install 直接更新；授权恢复前检查配对和预检，pending 未协调时不执行。卸载后重装创建新安装 ID，不能复活原私有 head。实验使用有界快照/总字节和统一操作预算；不无限累积回滚回执。

回滚必须选择仍保留的历史配对，并重新验证包签名、发布者绑定、快照完整性、Schema 和真实运行预检。通过同样的准备/完成流程恢复旧包和旧状态，世代只前进、清授权，不做反向字段转换。管理数据库不接触 Core，因此本实验不宣称已经证明真实知识和 outbox 在回滚后保留。

## 验证和限制

[验证入口](../../../experiments/extension-package/validate.py) 使用仓库外作者构建的签名包，验证真实偏好保留、新字段由 Wasm 添加、故障迁移、普通更新旁路、显式回滚以及初始化/升级/回滚各提交点的进程终止。逐项实际成绩和未执行范围以 [结果](../../../experiments/extension-package/RESULTS.md) 为准。

SQLite BLOB 候选仍只有一个管理事务资源；FULL 同步和进程终止恢复不等于断电或跨平台文件可靠性。执行为本地单写者串行，不包括长驻 worker、并行持久撤权、正式插件私有存储 API、真实阅读或移动渠道。原生编译和宿主代码不被 fuel 抢占。

## 依赖

生产 Workspace/依赖不变。两个实验新增 dev-only wat 1.228.0，用来在测试进程内编译正反例模块，避免测试依赖预先构建的作者可执行文件；[依赖策略](../../../config/architecture.toml) 登记 normal/dev/build/target 和解析闭包。发行 SDK 继续只导出权威公开包格式/API，剔除安装器、运行器、数据库和测试依赖。
