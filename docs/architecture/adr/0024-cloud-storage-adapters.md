# ADR 0024 云存储采用可替换适配器

日期：2026-11-08。状态：采用设计边界；尚未接入云服务。

## 背景与范围

用户要求预留云存储，通过适配器接入，候选包括 Supabase 和 Cloudflare 数据库。关联 C-10、F-SYNC-01/02、F-DATA-01。这不决定首版同步排期、默认联网行为或供应商，也不授权创建云资源、连接账号或上传资料。

## 决定

本地 SQLite 与原件库继续承担设备数据权威。云端提供授权范围内的同步副本和可选原件备份，不成为离线读写前提。

应用与同步编排依赖供应商无关的 ports；具体实现放在 adapters，由应用装配选择。Core、领域实体、公开插件 SDK 不依赖供应商 SDK、SQL 方言、账号 ID 类型或对象 URL。功能插件继续通过公开宿主能力访问数据，不自行旁路同步与出站授权。

按职责预留三类边界，实际实施时才创建接口与模块：

| 边界 | 职责 |
|---|---|
| 结构化同步后端 | 幂等提交、版本条件、变更拉取、连续游标、快照与删除记录 |
| 对象存储 | 不可变文件上传/下载、哈希校验、上传完成确认与清理 |
| 身份与会话 | 凭据获取/刷新及身份映射；服务端独立验证账号与知识库权限 |

三类能力可以分别选用供应商，不要求数据库、文件和身份绑定同一家服务。供应商身份通过显式绑定关联稳定的 QUSOR 用户/知识库标识，不能把切换服务商等同于替换 owner 字段。

Supabase、Cloudflare 均为候选适配路线。具体 Cloudflare 数据库产品及配套对象存储待验证时确定；不假定它们与其他候选拥有相同事务、认证、推送或一致性能力。客户端调用受控同步服务协议，不能获得管理员数据库凭据。必要的服务端逻辑也归基础设施实现，不能要求 Core 使用供应商专有 RPC 或表结构。

## 一致性与恢复

各适配器必须实现同一同步语义：本地业务、审计和 outbox 原子提交；网络重试幂等；条件更新防止静默覆盖；拉取只推进连续已落盘前缀；一致快照保留未确认本地操作。实时通知仅作唤醒提示，不承担持久投递保证。

缺少所需原子性或排序保证时，适配器须通过受控服务补齐并验证；无法满足时拒绝启用相关能力，不用时间戳覆盖或静默降低一致性。协议版本、认证失败、权限不足、冲突、限流、暂时不可用与快照失效须映射为供应商无关的结果。

对象上传与数据库登记不假设跨服务事务：先上传并核验，再登记引用，失败可重试，孤儿对象延迟回收。规范知识 ID、原件哈希、来源锚点和导出格式不含供应商地址；远端对象标识保存在适配层映射中。

切换后端是显式迁移作业：保全本地数据及未确认 outbox，建立新的后端绑定与同步代际，校验完整快照、原件和引用后才切换。旧后端游标与回执不能用于新后端；旧异步响应不能写入新会话。迁移失败保留可恢复的旧绑定及本地内容，远端清除另行处理。

## 验收与后续实施

- 同一组契约场景在各候选真实后端执行：重复提交、提交后丢响应、并发冲突、分页缺口、快照恢复、删除不复活、跨账号/库拒绝。
- 断网仍能完成本地阅读和保存；恢复网络不丢重、不覆盖未确认内容。
- 文件传输中断可恢复，下载哈希一致；未获授权的原件与内容不得出站。
- 更换适配器不修改领域模型或功能插件；迁移后 ID、内容、引用保持可用。

本次仅落设计与范围记录，无新增依赖、Workspace member、云迁移或实现。历史同步研究中的 Supabase SQL/RLS/RPC 属于候选实现材料，不是通用协议前提；真实接入前重新核对供应商官方文档并完成独立实验。
