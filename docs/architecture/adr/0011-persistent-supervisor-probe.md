# ADR 0011 同一长驻宿主中的多插件进程监督实验

日期：2026-11-08。状态：独立实验增量，生产集成未通过。关联 C-08、F-EXT-01/03/05/06、EXT-B03/B04、EXT-P04/P06/P11 的本机子项。沿用 [生命周期规格](../../product/plugin-lifecycle.md) 和 [恢复架构](../plugin-lifecycle.md) 的长驻监督要求。

## 问题

既有 Wasm 看门狗每次启动新的宿主进程，不能证明故障插件与正常插件共存时的隔离。单次同步包调用也不能证明管理入口在 host call 等待期间仍响应，或回收未知时不会并行启动替代者。

## 决定

继续使用独立包实验，新增长期持有 Store 单写者锁的 supervisor 和受限 JSONL 管理入口。它从已有完整签名安装和持续授权恢复新会话，读取管理库内冻结模块，启动本机子进程；不重新读取下载路径。官方与普通测试包没有身份特权。

worker 只取得当前运行的模块和临时通道标识，不取得数据库路径、Store、Host、授权记录或实体写入接口。managed runtime 不创建任何授权或合成服务，guest 的公开 0.1 capability request 只能经 IPC 交给父 broker。父 broker 的运行消息门不执行 guest 预检，复用纯策略校验检查安装/包摘要/世代/会话与精确资源，返回显式 synthetic 元数据；结果接受再次检查当前权限。

worker 通道由父侧创建并绑定 run ID，不能通过子进程自报身份切换安装。每次显式调用使用新会话和 run ID；结束、取消或撤权时关闭旧调用入口。迟到事件只可记录为过期，不能成为新实例的成功结果。

父事件循环有界处理管理消息、worker 消息、超时和退出状态。启动数据与回复由有界写通道发送，避免大模块写管道阻塞父循环。等待单个 broker 故障的测试不阻塞整个父循环；过程看门狗覆盖 guest 无响应和 IPC 等待，其他安装与管理入口继续可用。运行器 fuel、内存和响应预算保留，native host 阻塞不由 fuel 抢占。

kill/wait 返回错误或无法确认终止时保留真实 Child 句柄并隔离对应安装；禁止替代实例，显式 reap 确认退出后才允许新会话。实验故障注入模拟控制调用失败，不声称实际操作系统权限失败已验证。连续启动失败有界，达到阈值持久清授权并要求修复；没有无限自动重启。

## 证据、体验与限制

[实验入口](../../../experiments/extension-package/README.md) 和 [监督协议](../../../experiments/extension-package/SUPERVISION.md) 记录管理消息、状态、预算和复现。验证在同一 supervisor PID 中交错 A 正常与 B 阻塞/循环/trap/异常退出，观察管理响应；测试真实已读事件延迟投递，在新实例完成后拒绝旧事件。跨进程安装、作者独立构建和宿主 hash 不变继续验证。

执行任务失败、逻辑撤权完成、资源回收确认和“需要修复”分开表达；不能把发送 kill 当作已回收，也不能把任务失败写成插件数据丢失。此实验没有产品管理 UI，协议 code 不作为未来直接展示给用户的文案。

本轮不证明任意同步父 provider I/O 抢占、supervisor 自身崩溃后的残留进程核验、真实 Core 提交/撤权交错、知识保留/导出、OS 权限沙箱、正式私有存储 SDK、NSH 或平台渠道通过。长驻的是管理进程，worker 按次调用，不宣称已实现跨调用保留来宾内存的服务。

生产 Workspace、依赖与业务边界不变；std 子进程/管道/有界通道承接实验，不引入未经验证的生产进程框架。具体通过/失败与剩余范围只以 [实测结果](../../../experiments/extension-package/RESULTS.md) 为准。
