# 背单词插件规格（F-LEARN-01 首个切片）

更新：2026-11-11。状态：用户当日明确要求开发背单词插件。首个切片已完成**公开能力 + Core 学习数据 + FSRS 调度 + 普通签名包读取/评分**：Host API 0.5（`vocab.read`/`vocab.review`）、`vocab-study-v1` 有界 wire、SQLite schema 4 词汇表、FSRS-5 调度内核与 `plugins/vocab` 普通包均已有测试和真实 SQLite 证明；原生工作台样例 UI 也已接入同一 0.5 wire 与真实 Core（先回想后揭晓、四档评分、计数同步、重开恢复），见 [ADR 0036](../architecture/adr/0036-vocabulary-study-capability.md) 与[实窗记录](../../experiments/nsh-reader/evidence/vocab-workspace-live/README.md)。生产安装/权限界面、词书导入与“从阅读收词”仍不在本切片内。

## 功能与范围

- **用户目标**：选择一本词书，按到期顺序复习或学习新词，对每张卡给出“不认识 / 模糊 / 认识 / 很熟”的评分，系统用 FSRS 安排下一次复习；进度可重开、可导出，卸载插件后仍能读取。
- **触发场景**：每天打开背单词工作区；先清到期复习，再按每日新词预算学习；关闭应用后重开继续；换设备/恢复时导出再导入。
- **入口**：宿主工作区中的“背单词”插件工作区（贡献类型 `vocab_workspace`）。当前切片只证明入口注册与数据链路，原生界面在下一增量。
- **本轮包含**：
  - 词书列表与 total/due/new 计数；
  - 学习队列：到期复习优先，之后按词书顺序引入新卡，每日新词上限 10；
  - 四档评分与 FSRS-5 记忆状态更新、下次到期、阶段（Learning/Review）；
  - 幂等提交：重复同一评分不重复安排，换卡片/评分报冲突；
  - Core 持久化、关闭重开、导出到空库恢复；
  - 普通签名包经 Host 0.5 读取与评分真实 Core；只读包不能评分；
  - 插件停用/卸载后 Core 数据仍可通过宿主通用入口导出。
- **本轮不包含**：原生工作区界面与实窗交互、语音/拼写/选择题等练习形式、词书导入与随包词库、从阅读或笔记收词、标签/搜索、提醒与通知、AI 释义或例句、云同步、账号、移动/Web；这些不以占位按钮伪装可用。

## 用户流程（目标形态）

1. 打开背单词工作区：显示词书列表与今日到期/新词计数。
2. 选择词书进入学习：先显示到期复习卡，清空后按预算显示新词。
3. 每张卡先只显示 term 与“显示答案”；揭晓后显示 meaning、example 与四档评分，用户评分。
4. 提交后显示下一次到期（分钟或天）与剩余数量，继续下一张。
5. 队列为空时显示“今天完成”，不自动扩大新词预算。
6. 关闭重开：到期时间、复习历史与今日已学数量保持；不重复计算。
7. 停用/卸载插件：数据仍在 Core；宿主通用导出包含词书、卡片、复习历史与当前安排。

## 插件与宿主边界

| 边界 | 责任 |
|---|---|
| 插件 `plugins/vocab` | 0.5 manifest、`vocab_workspace` 贡献、普通 Wasm guest；只通过公开 wire 读取/提交；不接触 SQLite、vault 身份、Host 对象或完整知识副本 |
| Host | 外壳、导航与返回、原生控件（后续增量）、会话与精确 `vocab.read`/`vocab.review` 授权、每次请求重核 grant 与 vault、错误分类与预算 |
| Core | 词书/卡片/当前 schedule/复习历史的唯一权威、事务与乐观并发、导出恢复；调度算法在 `learning-domain`，应用用例在 `learning-application` |
| 可信适配器 | `VocabBridge` 把有界 wire 映射到 Core 用例；不授予权限、不重新实现调度 |

- 插件与第三方使用同一能力、贡献与授权链路；不按包 ID 写业务分支。
- 停用/卸载：工作区入口消失；Core 数据保留并可通用导出。删除学习数据是单独的用户动作（后续增量）。

## 数据与来源

- 数据归属：Core。词书、卡片、复习历史与当前 schedule 都是用户学习数据，插件私有状态不能成为唯一副本。
- 词书内容：本切片由宿主/可信应用播种**合成示例**（3 个词，明确标注不是授权词表）；真实词库的随包数据、导入与授权在后续增量定义。
- 复习历史追加写并记录算法标识 `qusor-fsrs-5-v1`；当前 schedule 由同一事务更新，重启后从历史与 schedule 恢复。
- 无网络、无模型调用、无按账号数据出站；导出是用户主动动作。

## 验收

- Given 一个 vault 中有注入的示例词书，When 打开学习队列，Then 先返回到期复习卡，再按位置返回新卡，单页不超过 wire 预算且返回剩余计数。
- Given 一张新卡，When 选择“认识”（Good），Then 记住下次到期约 3 天、阶段为 Review；选择“很熟”（Easy）约 16 天；选择“不认识/模糊”进入 10/30 分钟学习步。
- Given 同一评分 operation id，When 重复提交，Then 返回同一结果且 Core 不新增复习记录；换卡片或评分提交同一 id，Then 报冲突。
- Given 只授予 `vocab.read` 的包，When 尝试评分，Then Host 在授权层拒绝且 Core 无写入。
- Given 评分后关闭并重开 Core，When 再次打开队列，Then 到期时间、复习次数与历史一致；未到期卡片不出现在到期区。
- Given 导出学习数据到空 Core，When 恢复并重开，Then 词书、卡片、当前安排与复习历史一致；对非空学习数据恢复报冲突。
- Given 篡改包或错误发布键，Then 包验证失败；Given 0.4 会话或旧 protocol，Then Host 拒绝 0.5 词汇请求。
- Given 停用/卸载插件，When 通过宿主通用入口导出，Then 学习数据仍存在；不依赖插件私有格式。
