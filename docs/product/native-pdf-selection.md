# 原生 PDF 选区资格规格

状态：[独立本机选区子项通过](../../experiments/pdf-provider/SELECTION_RESULTS.md)，后续 [复合收录](compound-pdf-capture.md) 已补齐实验内多段原子保存；后续 [NSH Surface 探针](../../experiments/nsh-reader/pdf-surface/README.md) 已取得真实页图/窗口触点与候选高亮子项证据；正式阅读 UI 未交付。关联 C-08/C-09、F-READ-01/03、F-SRC-01、F-NOTE-01、F-EXT-04/06。

## 目标与入口

将真实页图上的指针动作变成可核对来源的选段。文档由原生 PDFium 服务冻结、渲染和提取，选区服务只消费该版本的字符映射；插件和 UI 不得自行声明字符位置成为事实。NSH 适配器将来只负责指针捕获、页面呈现与变换，不把窗口对象传入 Core。

页面同时存在三种坐标：PDF user space、固定渲染图的像素、窗口 DIP。展示倍率、设备比例、页面原点及滚动共同定义可逆变换；不得把屏幕坐标或缩放写入永久锚点。当前 frame 报告 hash 含渲染证据，与 C1 的语义提取 revision 分开。

## 手势与反馈

- 仅唯一、可靠的字形命中开始选择。空白、未知映射、多个重叠候选均给出明确状态，不吸附附近文字。
- 活动手势绑定 pointer ID、原件/页/报告版本及 viewport generation。其他 pointer 不能替换 anchor 或结束当前手势。
- move 无可靠命中时清除可提交预览；up 不能沿用最后一次有效位置偷偷选文。无 down 或重复 up 不产生选段。
- cancel、lost capture、窗口关闭不产生可提交选段，更不写入 Core。活动拖动中缩放、滚动、DPI、resize 或换页须取消，避免不同坐标变换混用。
- 完成的语义范围和临时像素叠层分开。新 viewport 不能复用旧像素叠层；原件或提取版本变化后不得自动沿用选段或批准。实验若采用保守清空结果，须明确记录，不把它当成已保存知识失效。
- 反向拖动保留方向，输出明确的半开 scalar 范围。grapheme 不得被拆开。无文本层页面仍可显示，但不能捏造文字选择。

## 多行及持久化边界

已资格的普通 LTR 行可按明确几何 profile 形成有序 segments，每段保留原 engine 索引、版本和精确引文。旋转页的引擎行序可能与阅读顺序不同；不能把各段的 min/max 变成一个吞掉其他内容的连续范围，也不能通过重排全文冒充 canonical reading text。

列布局、异常方向、行重叠或无法确定关系时返回不支持或歧义。该 profile 只能证明所测语料，不证明所有 PDF 的可靠阅读顺序。

指针 up 只产生候选，保存仍由普通插件提案和原生批准完成。单段结果可沿 C1 真实链路验证；多段在未接入版本化复合锚点与单一 Core 事务前只能预览，不得循环调用单段保存后宣称一条笔记成功。完整目标仍包含多行/跨页原子收录、键盘/触控、NSH 和可访问性。

## 验证

使用真实 PDF 的原生页图与字形像素确定输入点，分别检查普通页、旋转页、正反方向、不同展示倍率/DPI/滚动、空白、版本变化、取消及迟到消息。合成重叠/损坏映射只证明负例处理，不充当实际字体或中文 PDF 成绩。单段应实际经仓库外签名插件保存、重启和恢复回源；多段明确验证不发生隐式部分保存。


## NSH 原生 Surface 的下一项验收

这是 C-08/C-09 已授权的 P03/P05/P07 前置验证，沿用 F-READ-01/03、F-SRC-01 和 F-EXT-04/06；不冻结正式 reader 插件的视觉设计，也不新增产品范围。

探针呈现真实 PDF 页图、页码和缩放，阅读区域保持稳定留白。选区用轻量叠层反馈，候选引文在独立区域显示，不能遮住正在选择的文字。引用原文与用户笔记分开；尚未接入持久保存时明确显示“未保存”，不提供会伪装成功的保存动作。空白点击不显示技术错误弹窗；不支持文字选择、文件/版本失效及加载失败有可理解的状态。

| 场景 | 可观察验收 | 证据边界 |
|---|---|---|
| 打开真实 PDF | 原件经受控 PDFium 服务渲染，NSH 原生 Image/绘制显示；页图与字符报告同版 | 截图加实际 native 渲染/资源日志；静态内嵌示例图片不通过 |
| 拖动选择 | 真正窗口 down/move/up 映射至已有选择服务；可见高亮与引文一致，反向不丢字 | 系统事件、服务结果和前后截图共同核对，不把脚本直接调用选择算法算窗口交互 |
| 页码与缩放 | 页码/倍率随操作更新，图像几何与命中坐标同步；活动选择取消 | 旧回调不在新页显示，不能仅改标签或放大旧叠层 |
| 取消及失去捕获 | 取消/窗口关闭不产生候选提交，跨窗口拖动不留下可提交残影 | 若当前平台捕获语义不足，记录缺口并保持未通过 |
| 范围核对 | 引文显示页码及原文身份；不以窗口坐标充当永久锚点 | 多段仍按版本2完整有序结果，不能首段截断 |
| 重开与后续收录 | 本项重开只验证资源重新加载；正式保存仍由普通插件和 Core 回执决定 | 不把探针状态、内存变量或渲染成功当成知识持久化 |

先在固定合成许可语料上证明上述路径，之后再补中文字体/组合态、键盘选择、触控与无障碍。未实际运行的场景保留未验证，不由已通过的 CLI 选区或原生窗口例子推导。
