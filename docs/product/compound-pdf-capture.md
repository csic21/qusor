# 多行 PDF 摘录的原子收录资格

状态：[独立本机子项通过](../../experiments/capture-core/COMPOUND_RESULTS.md)，不代表 NSH 阅读 UI 已完成。关联 C-08/C-09、F-READ-02/03、F-NOTE-01、F-SRC-01、F-DATA-01、F-EXT-01/02/03/05/06。

## 用户行为

用户选择多行后看到完整引文、每段位置及个人备注，确认一次保存成一条摘录。所有段必须同时保存；失败不留下第一段或部分引用。回复丢失按同一个操作 ID 查询，重试返回同一条回执。取消、错误版本或任何一段不匹配均不保存。

Native 选区服务提供已经核对来源的有序分段。普通插件先通过公开 SelectionRead 取得完整上下文，再构造版本 2 的 CapturePropose。插件不能替换第二段、改变顺序或用旧单段协议悄悄降级。宿主的批准绑定完整复合内容、文档、安装、会话与授权世代。

每段保留页码、原件/提取/页文本版本、半开 scalar 范围和精确引文。数组顺序是显式引用顺序；旋转页不能按 engine 索引重新排序，也不能用 min/max 合成连续区间。显示文本按明确分隔符连接，分隔符是呈现规则，不冒充原 PDF 的字符。

## 兼容与恢复

旧文本、单段 PDF、回执及原有哈希保持可验证。旧提案读取、查询和定位入口遇复合记录应明确拒绝，不能仅返回首段。新归档明确标识版本 3；旧 V2 文本/PDF 资料仍可恢复，不能将复合记录伪装成旧格式导出。

完整导出及空库恢复必须保留原件、全部分段、顺序、备注和一次提交的操作关系。卸载、升级、回退插件不删除规范知识。真实崩溃覆盖提交及恢复边界，任何可见状态都不能只有一部分分段。

## 本轮门槛

以真实普通页和 90° 旋转页的字形像素生成指针选区，经过仓库外 SDK 作者构建的普通签名包完成整组收录、重启、归档及恢复回源。无 UI 时仅记录服务资格；原生窗口、跨页手势、键盘/触控及全部排版仍逐项验收。

本轮公开请求/响应维持实际 4KiB 预算，2–8 段；超限明确拒绝，不截断或分批伪装成功。该资格上限不替代完整产品范围，长选区与跨页能力仍须相应协议及体验验证。
