随后按 [ADR 0010](../architecture/adr/0010-paired-private-state-probe.md) 完成本机私有状态迁移/成对回滚实验子项：真实作者 Wasm 转换副本、预检及各提交边界进程恢复。仅管理实验私有偏好，不含正式知识、真实阅读或生产安装器；长驻监督和原有平台/业务门槛保持。

2026-11-08，按 [ADR 0011](../architecture/adr/0011-persistent-supervisor-probe.md) 补充同一长驻宿主双插件监督的本机子项，父进程持有真实策略并逐次判权、隔离未知回收、拒绝旧结果。未改变 C-08 的产品范围；自身崩溃协调、正式 Core/NSH/平台门槛仍未通过，不据此实现未确认的 AI/云功能。

## 首版推荐闭环

建议以“导入 PDF/EPUB → 阅读 → 高亮/批注 → 笔记 → 重开回源 → 导出恢复”为基础。中文搜索、异常资料处理、基础无障碍属于交付质量，不单独推迟为装饰。

Reader AI 按原愿景建议保留 M0，但当前问题允许用户选择延后。如果上线 AI 回答，F-AI-02 必须同时具备；如果允许 AI 保存内容，F-AI-03 同时具备。

画布/知识图谱建议 M1。富文本建议在 Markdown 基线可靠后扩大；无 DRM 的常见 PDF 与可重排 EPUB 为候选首版支持范围，不预先承诺所有电子书排版。

用户随后接受以本地阅读闭环推进的实施顺序，见 C-08；本节 Reader AI/画布等首版范围和具体支持深度仍是建议，未据此自动确认。
