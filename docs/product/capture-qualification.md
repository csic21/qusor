# C0 捕获、快照与定位资格切片

状态：独立实验的 [本机资格验证通过](../../experiments/capture-core/RESULTS.md)；不表示正式阅读器已交付。关联 F-EXT-01/02/03/05/06、F-SRC-01、F-DATA-01，以及 [下一阶段计划](next-phase.md)。

## 用户流程与验收

普通身份的签名来源插件通过公开契约提出来源、不可变文本和选段。宿主先显示来源、选段和草稿摘要；用户确认该摘要及自己的备注后，宿主再次检查安装身份、会话和授权，再提交 Core。预览和取消不产生知识记录；插件提供的文本不能充当用户批准或用户观点。

保存成功须有持久化凭据。回复丢失后可以按操作 ID 查询原凭据；同一操作和相同内容重复提交只产生一次保存，同一操作变更内容须拒绝。两次独立保存意图即使文本相同，也分别保留记录。撤权先取得提交门时禁止保存；提交先取得门时保留唯一凭据，后续撤权不删除已保存知识。

重启宿主、卸载或回退来源插件后，仍能读取原文、来源、选段和用户备注，并导出、恢复到空库。导出包括知识及必要审计来源，不包含插件代码、活动授权、批准令牌或凭据。恢复失败不留下可见的半份知识。

## 文本与定位范围

本轮使用有界原始 UTF-8 文本及 `qusor-raw-text-v1` 归一化标识，不进行隐式 NFC、HTML 提取或换行改写。定位单位为 Unicode scalar，选段边界还须落在 grapheme 边界；以中文、emoji、组合字符和重复段落验证。快照版本、哈希、单位或归一化不匹配均显式失败。仅提供引文而出现多个匹配时返回歧义，不取第一处或相似文本。

本地精确定位仅对已保存快照成立。外部来源最多提供来源入口，不声明可精确跳回外部选段。C0 公共 URI 仅接收不含用户信息、查询和片段的 HTTP(S) 地址，且不访问网络；这不是完整来源 URL 产品策略。

## 资格门槛

两个不同来源夹具使用同一公开契约，作者在仓库外仅凭导出的契约及签名 SDK 构建，宿主不按来源名称分支。实际 Wasm 调用经过父端 broker，来源插件不能直接访问 Core 数据库。

原始 blob 可靠发布后，知识实体、来源、锚点、备注、操作凭据、审计、outbox 与索引在同一 SQLite 事务内写入。以真实进程退出验证发布和提交边界；未引用的孤立 blob 不等于已保存知识。导出、空库恢复和失败定位均须有实际执行证据。

本轮不包含 PDF/EPUB 解析、微信读书账号接入、NSH 阅读 Surface、云上传或正式 SDK 发布。实验通过后才决定生产集成，不能用本轮成绩替代其他技术门槛。
