# 想法插件规格（F-NOTE-01 / F-SRC-01）

更新：2026-11-10。状态：首个正式切片为**读取与整理**（列表、分页、筛选、搜索、详情、完整正文、复制、回源、右键与键盘）；原生样例 UI v1 已按本规格实现并通过 6 项 headless 交互测试，见[UI v1 记录](../../experiments/nsh-reader/evidence/notes-workspace-ui/README.md)，但数据仍是 fixture、尚未成为安装包。编辑、删除、标签与收藏等写入能力在后续增量，需先有 Core 写入用例、历史/撤销与公开写能力。关联 F-NOTE-01、F-SRC-01、F-READ-03（读取侧）、F-UX-01/02、F-EXT-01/03/04/05/06；交互见[想法工作区设计](../design/notes-workspace.md)，读取模型见[ADR 0034](../architecture/adr/0034-note-read-model.md)，阶段见[D 阶段计划](d-phase-plan.md)。

## 功能与范围

- **用户目标**：回看保存过的原文摘录与自己的观点，快速确认来源、复制引用继续写作；想法不再埋在阅读窗口里，也不与原文混为一谈。
- **触发场景**：读完一段后想整理；写作时需要引用；关闭重开后想找回上次的想法；想确认某条想法出自哪份资料哪一页。
- **入口**：宿主工作区导航/功能目录中的“想法”插件工作区；阅读插件保存成功后的“查看想法”；窄窗下从列表进入详情再返回。
- **已确认行为**（来源：C-08、F-NOTE-01、F-SRC-01、ADR 0013/0019/0034）：原文与个人观点分开保存；保存成功以 Core 回执为准；预览截断不改变持久内容；停用/卸载插件后规范内容仍可由宿主通用入口读取与导出。
- **本轮包含**：
  - 想法列表：按提交倒序、稳定分页（`next_cursor`）、每页条数与预览有界；
  - 筛选：全部想法、当前资料；搜索：标题/引文/想法的有界本地过滤；
  - 详情：引文、个人想法、资料标题、页码、保存时间、复合选区标记；
  - 完整正文：预览截断时按块读取并展示，读取失败保留预览与明确状态；
  - 复制：复制引文、复制想法、复制引用（含出处与页码）；
  - 回源：当前资料直接打开所在页；其他资料明确提示“先打开《…》”，不假装定位；
  - 右键菜单、文本选取、键盘导航与窄窗列表/详情切换；
  - 状态：加载、空、错误、原件缺失、预览截断、只读。
- **本轮不包含**：编辑/删除想法、标签、收藏持久化、跨库全文检索、AI 生成或改写、外部服务回跳、EPUB、移动端与发布渠道；这些不以占位按钮伪装可用。

## 用户流程

1. 进入想法工作区：宿主保留工作区身份与可信返回；插件提供自己的筛选导航、搜索、列表与详情。
2. 列表：默认全部想法、最新在前；滚动到底或“加载更多”用游标继续；当前资料筛选只显示该资料的条目。
3. 搜索：输入即过滤当前已加载页，结果为空有明确空态；搜索不改变 Core。
4. 选择：单击行选中并显示详情；方向键移动选择；Enter 打开来源；Shift+F10 或右键打开菜单。
5. 详情：引文与个人想法分区显示；文本可选取复制；预览截断时提供“读取完整内容”，分块加载期间显示进度，失败保留预览并说明。
6. 复制：菜单或快捷键复制；界面给出“已复制引文/想法/引用”的就地状态，不弹系统通知。
7. 回源：当前资料打开所在页并返回阅读；其他资料提示需先打开；原件缺失或版本不符显示不可定位原因。
8. 取消/失败/离线：全部只读，不产生半保存状态；Core 读取失败显示“暂时读取不到，已保存内容没有丢失”，提供重试；不自动清空列表或选中项。
9. 窄窗：列表与详情单列切换；返回列表保留筛选、搜索、选中项与滚动位置；宿主外层返回仍回到进入前工作区。

## 插件与宿主边界

| 边界 | 责任 |
|---|---|
| 插件 `plugins/notes` | 独立包目录与仓库外 SDK 构建的普通签名包（当前 guest 为 WAT，作者构建锁文件在仓库外生成）；提供 `notes_workspace` 贡献；只通过公开 SDK 读取想法；不持有 SQLite、NSH 对象或完整知识副本 |
| Host | 外壳、导航与返回、原生控件与焦点、右键菜单/选取/剪贴板、公开 notes 读取能力的策略与预算、可信后端调用 Core |
| Core | 规范引文/想法/来源锚点、分页与正文读取（ADR 0034）、导出恢复；插件停用后仍可读 |

- 公开能力：`notes.read`（协议 0.4，待 ADR 0035 记录）；guest 不自报 vault/document，范围由 Host 绑定；单次响应受公开预算约束。
- 插件与第三方使用同一贡献点、授权与生命周期；不按包 ID 写业务分支。
- 停用/卸载：编辑入口停止，列表/详情/复制/导出仍由宿主通用入口可用。

## 数据与来源

- 数据归属：Core。引文是不可变来源快照；个人想法是用户内容；二者分区展示、分区复制。
- 读取：分页与正文块只读；预览截断只影响显示。
- 无云、无模型调用、无外部账号；不新增数据出站范围。
- 删除/恢复、标签与收藏在写入增量中定义，届时需要历史、撤销与冲突规则。

## 验收

- Given 同一 vault 有两个资料的已保存想法，When 打开想法工作区，Then 默认按最新在前分页显示，切换“当前资料”只显示当前资料，其他资料不被伪装成当前来源。
- Given 一条想法正文超过预览长度，When 选择“读取完整内容”，Then 分块读取后展示完整正文，字节数与 Core 一致；读取失败时预览保留并显示可重试状态。
- Given 选中一条当前资料的想法，When 选择“打开所在页”，Then 阅读打开该页；Given 其他资料，Then 明确提示需先打开，不跳转。
- Given 选中引文或想法文本，When 右键或按复制快捷键，Then 剪贴板得到对应内容，界面显示已复制；引用格式包含资料标题与页码。
- Given 仅使用键盘，When 用方向键、Enter、Shift+F10 与 Escape 操作，Then 可选择、打开、弹出菜单与返回，焦点不丢失。
- Given 900×680 窄窗，When 从列表进入详情再返回，Then 筛选、搜索、选中项与滚动位置保留，宿主返回仍回到进入前工作区。
- Given 插件被停用/卸载，When 通过宿主通用入口查看，Then 已保存引文与想法仍可读、可导出；不以插件私有格式存唯一副本。
