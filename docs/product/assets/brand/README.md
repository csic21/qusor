## 来源与使用

- [第二版概念板](qusor-logo-concept-v2.png) 是用户认可的视觉方向；[第一版概念板](qusor-logo-concept-v1.png) 仅作历史记录。
- [独立素材生成提示词](qusor-logo-assets.prompts.txt) 保留三份生成式输出的请求；概念板提示词分别见 [v1](qusor-logo-concept-v1.prompt.txt) 与 [v2](qusor-logo-concept-v2.prompt.txt)。本地派生的两项没有新的生成提示词。
- 保持标识宽高比和留白；不要拉伸、增加渐变或重新组合回环结构。
- 黑色透明图用于浅底，白色透明图用于深底；透明图片在同色背景上可能看不清，并非空文件。
- 本轮交付是 PNG，尚无统一 SVG 母版或各平台图标包。生成式提取不保证与概念板像素级一致。

## 本地派生记录

2026-11-07，用户明确回复“允许”，授权使用本地裁切与换色完成剩余素材。实际处理使用 Windows System.Drawing，未重新生成或绘制回环结构，也未裁掉任何标识部分。

- 白色标识：以黑色标识为源，画布与 Alpha 通道保持不变，所有像素 RGB 改为 (255, 255, 255)。透明孔洞、交叉缝隙与边缘覆盖率均沿用源文件。
- 应用图标：输出 1024 × 1024。黑色圆角方形位于 (40, 40)，边长 944，圆角半径 208；完整白标画布等比缩放到同一区域，复用源图自带留白。先以 2 倍尺寸合成，再高质量缩小以平滑边缘。圆角方形外部透明，内部黑底不透明。
- 三份原有独立 PNG 保留原样，处理前后 SHA-256 一致。
