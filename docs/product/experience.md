## 工作状态

2026-11-08，用户新增本机编程、电脑操作与多 Agent 调度需求。新增执行工作状态，见 [Agent 工作台设计](../design/agent-workbench.md)：机器/项目/执行方持续可见，待处理集中呈现，任务、会话和终端分离，接管与停止清楚。阅读与思考沿用下述基线；执行状态不自动开启屏幕采集或扩大资料范围。

阅读状态用暖白纸张、低对比辅助色、稳定文本宽度和充足留白；深色/浅色/纸张主题保留。正文、目录和阅读位置是主信息；AI不默认常驻侧栏，不自动替用户生成干扰阅读的内容。

思考状态允许深空蓝紫与自由画布，用颜色/形状辅助表达节点类型；不能仅靠颜色区分原文、AI和用户内容。动效服务于关系、选中与布局变化，提供减少动效设置。性能和可读性优先于粒子装饰。

## 核心用户旅程

| 场景 | 入口与主要动作 | 完成与失败反馈 |
|---|---|---|
| 导入资料 | Library中选择文件，查看导入状态 | 显示可读/处理中/失败/受限格式；保留原文件，失败可重试 |
| 安静阅读 | 从Library打开，按需显示目录/工具 | 进度在持久提交后显示已保存；不因云端不可用阻止阅读 |
| 选区提问 | 选中文字后主动选择解释/翻译/提问 | 显示使用范围和来源；云AI尚未配置则提供配置入口，不自动上传 |
| 保存想法 | 创建用户笔记或审核AI建议 | 原文引用、用户观点、AI推断可辨；接受后可撤销 |
| 回到来源 | 点击笔记或证据引用 | 精确定位；原件缺失/版本变化/多匹配明确提示，不随意跳近似句 |
| 研究主题 | 从选定资料/笔记创建主题Canvas | 节点/关系可编辑；列表和检查器可完成基本操作 |
| 跨设备继续 | 从设备位置中选择继续，查看同步状态 | 缺原书可见；冲突保留双方，不能只显示“同步成功” |
| 插件收录外部选段 | 从实际可用的外部阅读/分享入口，预览选文及出处后加入知识库 | 本地已保存后才提示成功；仅有摘录时明确范围，外部只能打开书籍时不声称定位到段落 |
| 管理插件 | 用户主动打开插件页，查看能力、启停和更新 | 卸载保留已收录知识；缺少插件/登录态仍能阅读本地快照 |
| 复习 | 从到期卡片进入，回答并查看反馈 | AI评价可纠正；实际复习记录与生成建议分开 |

这是长期旅程设计，不表示所有入口进入M0。

## 桌面和移动

桌面支持多面板深度阅读、键鼠选择和研究整理；移动优先单任务阅读、快速笔记、问答和复习。移动画布采用聚焦节点/局部邻域和检查器，不强制复制桌面的密集面板。

字号、字体回退、触控目标、键盘避让和屏幕阅读器属于结构设计。跨端使用相同数据含义，界面布局不要求逐像素相同。

## 必须设计的状态

每个功能规格应选择实际相关状态：空资料库、导入中、离线、未配置模型、预算/网络错误、文件缺失、引用歧义、待审核、保存失败、冲突、迁移中与恢复完成。

“已保存”表示本地持久提交；“已同步”表示相应同步确认，二者不能混用。原书未上传不代表引文/笔记/云模型请求没有出站；界面应说明当前动作涉及的数据范围。

## 来源与AI显示

每段内容保留来源类型，引用可以打开原文；AI推断不能呈现为原文高亮。用户接受AI建议后仍保留AI来源，同时记录用户审核。

AI修改预览显示新增/修改/删除与影响项，支持分项选择；拒绝不改变正式知识库。版本已变化时展示新的差异，不复用旧批准。

## 插件体验约束

扩展入口通过宿主菜单、选区动作、列表和表单呈现，不自动占据阅读侧栏。授权、AI审核、来源可信标识由宿主控制，插件不能自行伪装。

“查看保存的选段”“打开来源作品/章节”“跳到外部原文选段”是不同结果。具体能力按当前验证显示，来源失效保留本地内容。用户直接点击收录可完成一次确定性保存；AI生成正式知识仍需要单项或批量审核。

插件升级/卸载不等于删除用户知识；跨设备同步知识不等于在新设备安装代码或恢复第三方登录。完整设计见 [插件架构](../architecture/extensions.md)。
