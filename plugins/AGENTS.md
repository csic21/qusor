# 功能插件开发约束

先读根 [协作约定](../AGENTS.md)、[目录架构](../docs/architecture/workspace-layout.md) 及 Feature 规格。当前目录只有规划，新增实现仍满足阶段门槛。

- 阅读及其他核心用户工作流在此独立成包；共享不变量和原生适配器归 Core/Host，不复制进插件。
- 官方/第三方用同一 SDK、贡献点、授权与生命周期；禁止依赖主仓库 Core/Host/application/storage/NSH 私有实现及官方包 ID 特权。
- 独立 Workspace/锁文件/版本，不加入生产根；构建不能隐含依赖根文件。仓库外构建、未重编译 Host 中安装为必要验收。
- 插件只提出授权命令/候选，不直写宿主库；AI 正式修改经过审核、版本校验和撤销。
- 停用取消任务并撤销资源，卸载保留 Core 内容；跨插件使用公开能力，不读取私有文件。
- 新依赖/包在根策略登记，运行真实契约/行为检查；目录、manifest 或模拟不算功能完成。
